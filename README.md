## 새 ChatGPT 채팅에서 게임 시작

새 대화에서는 **[BOOTSTRAP.md](BOOTSTRAP.md)**를 먼저 읽어 세계관·13영주령·11신/7마왕·GM 비밀·장면 JSON 규칙을 복원한다. GitHub 문서는 새 채팅의 모델에 자동 주입되지 않으므로 처음에 저장소 문서를 명시적으로 읽어 달라고 요청해야 한다.

# 에르세디아 RPG 웹 UI

ChatGPT 웹페이지 내부의 고정 게임 화면과 GitHub UI 업데이트는 [Tampermonkey 설치·사용 안내](tampermonkey/README.md)를 참고하세요. 런처와 게임 UI는 분리되어 일반 UI 패치 때 재설치가 필요하지 않습니다. 실제 ChatGPT 자동 연결과 v1.1 전체 업데이트 동작은 사용자 확인 대기 상태입니다. 로컬 수동 게임 화면은 `http://localhost:4173/?game=1`입니다.

기존 `prototypes/low_lag_vn_v03.html`의 대화를 기반으로 한 독립 실행형 비주얼 노벨 UI입니다. 세계지도는 등록된 메인 표시용 `assets/maps/world/world_main.png`를 사용합니다. AI API 연결은 없습니다.

세계지도 최신 갱신: 벨로아·드라켄·루메린 왕국과 정식 영주령 13곳을 표시합니다. 영주령을 누르면 이름·영주·가문·경제·지형·인구·상비 전력을 확인할 수 있습니다. 국경·행정 경계와 왕도 도시명은 미정입니다. 지도 이미지 CDN은 지형을 보존해 왕국명을 갱신한 커밋 `2117dcd5f2f61dbe4c9de3452a255d2c22403d1b`에 고정했습니다. 아래 구버전 지도 검증 기록은 초기 구현 이력이며 최신 지도 검수는 assets/maps/world/README.md를 참고하세요. 런처 재설치 없이 UI 업데이트 확인·선택 적용 구조를 유지합니다.

## 실행

Node.js가 설치된 상태에서 이 폴더에서 `node server.mjs`를 실행하고 http://localhost:4173 을 엽니다. npm이 설치되어 있으면 `npm start`도 가능합니다. 별도 패키지 설치나 빌드가 필요하지 않습니다. 종료는 실행한 터미널에서 Ctrl+C입니다. `index.html`을 파일로 직접 여는 대신 HTTP 서버로 실행하세요.

현재 PC의 Codex/Work 브라우저에서도 같은 주소로 접속할 수 있습니다. localhost 링크는 이 PC에서 서버가 실행 중일 때만 유효하며 공개 배포 주소가 아닙니다. 이미지는 등록된 jsDelivr CDN에서 가져오므로 최초 로드에는 인터넷 연결이 필요합니다.

## 조작

- 화면 클릭, Enter/Space 또는 다음/이전 버튼으로 기존 대사 4개를 넘깁니다.
- 오른쪽 위 전체화면 버튼으로 게임 화면을 확대합니다. 다시 누르거나 Esc로 돌아옵니다. 브라우저가 전체화면 API를 지원하지 않으면 브라우저 영역을 채우는 방식으로 동작합니다.
- 세계지도에서 지역과 지점 표식을 클릭하거나 Tab 후 Enter/Space를 눌러 설명을 확인합니다. 왕도·영주령·항구·요새·광산·위험 지역·군도 후보 24곳과 지역 7곳이 선택됩니다. 대화로 돌아와도 진행 위치가 유지됩니다. 지도는 지리 검토용 시안이며 실제 이동 기능은 없습니다. 솔브린 마을는 지도 위치가 미정이므로 지도에 임의 배치하지 않습니다.
- 지역명이나 위쪽 지역 버튼을 누르면 해당 구역이 확대되고 등록된 세부 지점 목록이 표시됩니다. 지점 표식을 직접 눌러도 그 지점이 속한 지역으로 확대합니다. 확대 화면에서 표식이나 목록으로 지점을 선택하고 '전체 지도'로 돌아옵니다. 대화·상태창으로 전환해도 확대 상태가 유지되며 설정 저장 후 새로고침에도 복원됩니다. 기존 원화와 등록 좌표를 확대하는 방식이며 새 세부 지도나 미등록 장소를 생성하지 않습니다.
- 갑옷·평상복·잠옷은 등록된 스탠딩 3종을 사용합니다. 기본·미소·분노·놀람·슬픔·부끄러움·두려움·불쾌함·애정의 공통 얼굴 9종을 복장 위에 합성합니다. 표정을 선택한 뒤 복장을 바꿔도 같은 표정이 유지됩니다. 얼굴과 몸체는 같은 위치·확대값으로 움직입니다. 얼굴 로딩 실패 시 해당 복장 원본의 기본 얼굴을 유지하고 오류를 표시합니다.
- 확대 260%, 좌우 50%, 상하 -120px가 기본값입니다. 무대 455px, 원본 표시 높이 410px, transform-origin center top을 사용합니다. 복장마다 배치를 따로 조절할 수 있습니다.
- 설정 저장은 복장별 위치·크기, 선택한 복장·표정, 레이어 표시, 대화 진행, 지도 선택, 현재 화면을 이 브라우저의 localStorage에 저장합니다. 새로고침 시 복원됩니다. 브라우저/주소가 다르면 저장 공간도 달라집니다. 배치 초기화는 현재 복장의 배치만 되돌리며 저장 버튼을 눌러 확정합니다.
- 상태창에서 주인공의 레벨·직업, 현재/최대 체력·마나, 현재/다음 레벨 필요 경험치, 근력·민첩·지능을 확인합니다. 상태창은 조회 전용이며 주인공 정보를 직접 편집하거나 저장하는 버튼은 없습니다. 실제 게임의 능력치 변경 연동은 추후 구현합니다. 아직 정하지 않은 정보는 미정/—로 표시하며 세린의 직업이나 외형을 주인공 정보로 사용하지 않습니다. 기존 저장값도 그대로 복원하면서 새 주인공 정보는 빈 상태로 시작합니다.
- 상태창은 대화 화면과 같은 509px 높이(무대 455px + 대사 조작부 54px)로 표시합니다. 긴 정보는 상태창 안에서 스크롤합니다. 스킬 등록·편집·삭제 UI는 현재 제외했으며 기존에 저장된 사용 가능 스킬의 이름·설명·데미지 공식·계산값만 조회합니다. 저장된 스킬 데이터는 보존됩니다. 공식은 STR/근력, DEX/민첩, INT/지능, LV/레벨, 숫자와 + - * / ( ) 및 × ÷를 지원합니다. 공식에 필요한 값이 비어 있거나 식이 잘못됐을 때는 안내를 표시합니다.

## 인벤토리

인벤토리는 대화 화면과 같은 높이의 32칸 슬롯 창입니다. 전체·장비·소비·재료·기타 분류로 확인하며, 슬롯에 커서를 올리거나 키보드로 포커스하거나 터치하면 이름·설명·효과·수량을 표시합니다. Esc로 설명을 닫습니다. 장비 사용·판매·이동 기능은 아직 연결하지 않았습니다.

초기 소지품은 비어 있습니다. '아이템 미리보기'를 누르면 세 종류의 UI 확인용 예시가 표시되며 실제 보유 데이터에는 추가하거나 저장하지 않습니다. 아이템 원화가 등록되기 전에는 분류별 기호를 표시합니다. 게임 소지품과 인벤토리 화면 선택은 기존 설정 저장에 포함됩니다.

향후 게임 로직은 아래 이벤트로 현재 소지품 전체를 전달할 수 있습니다. 데이터가 들어오면 기존 슬롯을 갱신하고 브라우저에 저장합니다. 저장 실패는 설정 안내에 표시됩니다. 필드는 name, category(equipment/consumable/material/misc), quantity, description, effect입니다.

```js
window.dispatchEvent(new CustomEvent('ercedia:inventory-update', {detail: currentItems}));
```

## 구조 및 원본 보존

대화/지도 DOM과 복장 이미지 노드를 처음 한 번 생성하고 계속 유지합니다. 메뉴와 복장은 hidden 상태, 대사는 textContent, 슬라이더는 CSS 위치·변환만 변경합니다. 슬라이더 입력은 requestAnimationFrame으로 프레임당 한 번 반영합니다. 메뉴 전환 시 이미지 src를 재할당하지 않습니다.

원본 이미지와 세계관·규칙·기존 프로토타입은 수정하지 않았습니다. 이미지 주소는 얼굴 9종이 등록된 Git 커밋 `2b8de39504ff4f3fdabcefa6f2b5a848babcd683`에 고정되어 있으며 로드 실패 시 오류와 원본 링크를 제공합니다. 초안 이미지는 매핑에서 제외했습니다. 공통 얼굴은 `faces/<expression>.png`를 재사용하며 복장별 합성 좌표는 `web/face-fit.js`에 있습니다. 갑옷 좌표는 faces/manifest.json에서 계산했고 평상복·잠옷은 기존 머리카락과 맞춰 보정했습니다. 3복장의 기본·미소·분노 합성을 이미지 비교로 확인했으며, 실제 브라우저에서의 최종 외형 확인은 사용자가 진행합니다.

## 검증

세계지도 이미지 URL은 지도 표시본이 등록된 커밋 `89ba7a06e5b7ed74d3157be77b7dbc1d716bcc35`에 고정되어 있습니다. 지도 이미지는 object-fit:contain, 클릭 SVG는 동일한 1536×1024 viewBox와 중앙 정렬로 표시하여 크기·전체화면 전환에서도 좌표가 일치합니다. 클릭 노드는 처음 한 번 생성해 재사용합니다. `web/map-data.js`는 `assets/maps/world/map_locations.json`의 지역·지점 좌표를 복사한 데이터이며 테스트에서 원본과 일치하는지 검사합니다.

지역 확대에서는 이미지와 클릭 SVG를 하나의 1536×1024 레이어에 묶어 같은 CSS 변환을 적용합니다. 확대 구도는 등록 지점의 범위와 화면 여백으로 계산하며, 사각형 구도는 국경을 의미하지 않습니다. ResizeObserver로 화면 크기·전체화면 변경에 맞춰 구도를 갱신합니다. 카메라 영역·다양한 화면 비율·지점 선택과 확대 저장값 복원을 추가 검사합니다.

`node --test tests/*.test.mjs` 또는 `npm test`는 저장·복원, 잘못된 저장 데이터, 저장 공간 접근 실패, 허용 범위 보정, 지도 좌표·해상도 일치, 모든 지점 선택값 복원, 주인공·스킬 저장 호환성과 공식 계산·오류 처리를 검사합니다. 사용자 요청에 따라 브라우저 시연과 클릭 확인은 사용자가 직접 진행합니다.
