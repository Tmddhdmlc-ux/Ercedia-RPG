# 궁극기 컷신 제작·설정 검수

최신 UI 명부 163명과 `characters/ultimate_cutin_plan.json`의 ID가 모두 일치한다. 원본 roster 4개와 인물별 시트·참조 PNG 경로/해시를 기록했다. 실제 아트 manifest는 `characters/art_registry.json`이며, 지시서 예시의 `assets/character_art_manifest.json`은 존재하지 않는다.

## 현재 산출물

제작 중 최신 main의 `ULTIMATE_SYSTEM.md`가 추가되어 재확인했다. 기존 세린 하이퍼 전체 원화와 ‘결의의 일섬’ 연출 명칭은 사용자 채택 기록이 있다. 이 승인과 새 익스퍼트 원화·새 하이퍼 얼굴 원화의 검수 대기를 구분해 metadata에 기록했다. 실제 습득·발동 조건은 별도이며, 승인된 기존 5초 연출 화면도 덮어쓰지 않았다.

- 세린 익스퍼트 전체 컷신 신규: `assets/characters/cutins/drafts/serin/expert_ultimate_v1.png`, 불투명 RGB PNG 1664×936, 정확한16:9.
- 세린 하이퍼 전체 원화: `assets/characters/main/serin/cutins/drafts/ultimate-flash-v1.png`, 기존 1672×941 원본을 변경 없이 연결.
- 세린 하이퍼 얼굴 컷인 신규: `assets/characters/cutins/drafts/serin/hyper_face_v1.png`, 불투명 RGB PNG 1664×936, 정확한16:9.
- 익스퍼트 얼굴은 전체 원화의 정규화 face_crop 좌표로 연결한다. 하이퍼 원화는 얼굴이 작아 별도 가로 얼굴 컷인을 제작했다.
- 내장 image_gen 모드, 실제 프롬프트·구도·원소 출처·참조 원화·크기는 `assets/characters/cutins/drafts/serin/metadata.json`에 기록했다.
- 원시 생성 크기는 1672×941이다. 새 PNG만 좌우4px와 상하2~3px 가장자리를 잘라16:9를 맞췄다. 확대·배경 제거·투명화·재조명은 하지 않았다. 1920×1080으로 생성했다고 주장하지 않는다.
- 두 단계 비교 및 반복 재생: `/tests/ultimate-cutin-art-preview.html`. 준비→얼굴→전체→타격 연출→복귀 흐름과 일시정지·배속·건너뛰기·다시보기만 보여준다. 실제 피해·HP·MP·승패는 판정하지 않는다.

세린은 현재 **베이직 나이트**다. `결의의 일섬`은 사용자가 지정한 미래/가정 연출 시안이며, 기술 지급이나 경지 상승을 뜻하지 않는다. 익스퍼트 그림은 좁은 중립 검광, 하이퍼는 기존 참고 원화의 강대한 광류를 표현한다. 효과의 색을 세린의 확정 원소 속성으로 등록하지 않는다. 새 원화는 사용자 최종 승인 대기이며 라이브 manifest에 추가하지 않았다.

## 보류 162명

`settings-audit.json`과 제작 대장에 인물·단계별 보류 사유를 기록했다. source와 개별 시트에는 승인된 대표 궁극기명·개별 원소·고유능력의 구체적 발동 현상이 등록되어 있지 않다. 마법탑 연구 분야, 성자/성녀의 친화성, 직업·소속·외모는 개인의 대표 궁극기를 확정하는 자료로 바꾸지 않았다.

지시서의 “원소는 해당 인물의 승인된 기술/능력에서만 정한다”와 “미정이면 element_status를 pending으로 기록하고 중립 검광 또는 보류한다”에 따라 물·불·바람·전기·암흑·비원소 타인 샘플은 보류했다. 세린 시안처럼 임의의 미래 능력을 전 인물에게 배정하지 않는다. 생활형 NPC, 낮은 경지, 마수와 미정 전투 계열도 대장에서 누락시키지 않는다.

보류 해제에 필요한 정보: 캐릭터 ID, 승인된 대표 기술과 실제 발동 동작/효과, 원소 또는 비원소 현상의 출처, 두 단계가 현재 기술인지 미래/가정 시안인지. 기술이 공격/방어/회복/구호 중 무엇인지도 확인한다. 새로운 기술이나 경지를 설정하는 작업은 이번 원화 제작에서 수행하지 않는다.

## 검증 범위

원화 육안으로 외형·눈색·머리·갑옷·손과 검 연결·구도 차이·절제된 효과·얼굴 가독성을 검수했다. 파일 규격과 불투명도·원본 보존·등록 제외 검사는 `validation.json`, 업로드 확인은 `delivery-validation.json`에 별도 기록한다. 브라우저 시연·실제 게임/Tampermonkey 플레이는 미검증이다. “전 캐릭터 이미지 완료”로 보고하지 않는다.
