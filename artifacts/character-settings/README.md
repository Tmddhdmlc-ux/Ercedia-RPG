# 캐릭터 설정 확립 검증

- UI 명부 163명의 설정 JSON, 원본 roster, 공개 catalog, 궁극기 제작 대장 ID가 일치한다.
- 기사 37 / 마법사 23 / 성직 22 / 생활인 47 / 일반 무예 14 / 마수 20.
- 기존 139명의 숫자 스탯·레벨·외형·소속·확정 경지 유지. 초기 경지 미정 인물만 전력과 배경 기술을 설정했다. 직업 분포를 맞추려 기존 인물을 재배치하지 않았다.
- 생활형 24명 초기 HP/MP/XP를 공식으로 검산했다. 근력·민첩·체질은 벌목·채굴·전령·용병 등 생업과 외형을 반영했다. 지능은 기록·감정·수선 등 역할, 마나는 비전투 생활인의 낮은 초기치로 설정했다.
- 기사와 마법사 60명의 저단계/고단계 연출 설계가 준비되었다. 59명 원화는 미제작이고 세린 1명은 기존 시안을 유지한다. 나머지 103명은 해당 계열 궁극기를 강제 부여하지 않는 사유를 기록했다.
- 새 기술서 아이템, 피해 공식, 기적, 궁극기 학습·장착·자원 소모·새 이미지 등록은 추가하지 않았다. 기술의 실제 사용 비용과 효과 수치는 기존 GM 사건 검증에 맡긴다.
- 공개 빌드에는 일반 주민의 스탯과 계열·대표 기술을 연결했다. 도적 2명의 정체·스탯·기술은 공개 catalog에서 계속 숨긴다. 새 게임 설정 원문에는 캐릭터 설정 JSON/문서가 기존 탐색 방식으로 포함된다.
- 기존 저장의 부상·전투 경지·레벨·학습 상태를 유지하는 검사를 포함해 총334개 테스트 통과. Tampermonkey 브리지·장면·저장 버전1 유지; 런처 재설치 불필요.
- 브라우저 클릭, 실제 ChatGPT 채팅 첨부, 진행 중인 세이브 20턴 플레이는 미검증이다.

`artifacts/ultimate-cutins/settings-audit.json`과 당시 validation은 이전 원화 제작 커밋의 설정 부족 상태를 기록한 과거 검증 자료다. 현재 개인 설정과 보류 상태는 `characters/combat_profiles.json`, `characters/ultimate_cutin_plan.json`을 우선한다.
