# 지역 환경음

CC0 외부 원음을 가공한 17가지 32초 스테레오 루프. BGM과 별도로 기본 음량 18%로 재생하며, 전투 중에는 설정 음량의 25%로 낮춘다. 장소 전환은 크로스페이드, 반복 경계는 1.2초 겹침으로 연결한다.

## 실제 게임 연결

`web/ambience.js`는 현재 장면의 등록 배경/장소와 `gameTimeView(state)`를 사용한다. 지도 탐색의 선택 지역은 사용하지 않는다. 마을·도시·숲은 저녁/밤/새벽에 조용한 버전으로 바뀐다. 실내, 던전, 비 오는 배경은 해당 환경음을 우선한다. 타이틀·도입·비활성 문서에서는 중지하며, 최초 사용자 입력 이후 재생한다. 환경음 메뉴에서 끄기와 음량을 설정할 수 있고, 설정은 버전 1의 전체 세이브 `uiPreferences.ambience`에 보관한다.

| 영주령 대표 배경 | 환경음 |
| --- | --- |
| W1 노르발트 | 산바람 |
| W2 발렌하르트 | 도시 낮/밤 |
| W3 엘름베르크 | 농경 마을 낮/밤 |
| W4 로젠펠트 | 국경 |
| W5 아르덴슈타인 | 교역 도시 낮/밤 |
| E1 칼트하임 | 산바람 |
| E2 아이젠크로네 | 공방 화로 |
| E3 베르크슈타인 | 국경 |
| E4 실베른 | 산바람 |
| S1 벨마리나 | 해안 물결 |
| S2 세르반 | 국경 |
| S3 아쿠아렌 | 해안 물결 |
| S4 솔메리아 | 농경 마을 낮/밤 |

세부 장소(왕궁, 숲, 시장, 여관, 야영지, 던전, 설산, 빗길, 극동, 미탐색)는 해당 음향을 우선한다. 영지 선택은 `LORDSHIPS.md` 공개 지형·민생을 참고한 사운드 디자인이며 새 세계관 설정을 확정하지 않는다.

## 출처와 재생성

`sources.json`에 원문 페이지, 저자, CC0 선택, 다운로드 주소, SHA-256 및 믹스 비율을 기록했다. `source/`는 원본 보관용이며 게임 런타임에 등록하지 않는다. 바람 원음은 Luke.RUSTLTD의 Pure Data 합성음이고, 해안 물결은 RandomMind의 강 녹음을 가공했다. 군중 녹음은 멀리 들리도록 필터와 음량을 줄였다. 궁극기 컷씬 음향은 이 변경에 포함하지 않는다.

Python의 `imageio-ffmpeg` 패키지를 설치한 뒤 저장소 루트에서 `python tools/build-ambience.py`로 재생성한다. 게임 등록 자산은 `integration/audio-assets.json`, 배포 빌드는 `node tampermonkey/build.mjs`다.

`tests/ambience-engine-demo.html`은 격리된 임시 세이브와 실제 게임 번들을 사용하는 시연이다. 장소/게임 시간을 선택하고 이동한 뒤 게임 화면을 클릭하면 들을 수 있다. 실제 ChatGPT/Tampermonkey 플레이를 검증한 것으로 간주하지 않는다.
