# 게임 엔진 연결

실제 장면의 현재 화자와 표정으로 짧은 비언어 리액션을 재생합니다. 대사 전체를 읽는 TTS는 아닙니다. `speaker_id`가 있으면 해당 인물을 우선하고, 여러 인물 장면은 각 인물의 표정을 따로 이어받습니다. 나레이션·전투 대사는 자동 성우 대상에서 제외합니다. 전투는 기존 스킬·타격 음향을 사용합니다.

전체 등록 163명에 배정했습니다. 사람 캐릭터 143명은 네 가지 공용 음색을 사용하며, 세린은 `female_young`입니다. `characters/npc_roster_100.json`, `characters/core_cast_stats_38.json`, `characters/common_npc_roster.json`의 명시된 성별·나이를 사용하고, 영주 13명은 `LORDSHIPS.md`의 해당 영주 항목을 조회합니다. 30세 미만은 어린 스타일, 그 이상은 중후 스타일로 분류하는 음향 편집 기준이며, 배우의 실제 연령을 뜻하지 않습니다. 성별·나이를 추측하지 않으며, 사람 캐릭터 배정 누락 시 빌드가 실패합니다. `tampermonkey/voice-build.mjs`가 레지스트리를 번들용 `web/voice-data.js`로 생성합니다.

몬스터 20종은 짐승·뿔짐승·멧돼지·작은 생물·파충류·날개 생물·벌레·수중 생물·영체의 9개 계열입니다. `assets/audio/monsters/monster-banks.json`에 원음·가공 이력을 기록했습니다. 말하는 몬스터의 장면 리액션도 해당 계열에 연결하며, 전투에서는 공격 시전 시 attack, 실제 피해 발생 시 hurt, HP가 0이 된 피해 시점에는 death를 한 번 재생합니다. 회피와 피해 없는 방어는 피격 발성을 재생하지 않습니다. 여러 개체는 `catalog_id`로 원본 몬스터를 찾습니다. 미등록 monster는 기본 짐승 계열을 사용합니다. 전투의 발성은 전투음 음소거·음량·일시정지 제어를 따르고, 비전투 리액션은 성우 설정을 따릅니다. 판정이나 전투 수치는 변경하지 않습니다.

게임 상단 ‘성우 리액션’에서 현재 화자의 네 가지 음색, 음량, 켜기/끄기를 선택합니다. `uiPreferences.voice`에 저장하고 복원합니다. BGM도 `uiPreferences.music`에 저장하므로 임베디드 저장 브리지에 음향 설정만 써서 전체 게임 데이터를 덮어쓰지 않습니다.

첫 사용자 입력 이후 재생합니다. 화면 갱신으로 같은 대사를 반복 재생하지 않으며, 대사를 넘기거나 음소거하거나 지도·타이틀·전투로 전환하거나 탭을 숨기면 이전 음성 및 지연된 로딩을 취소합니다.

`tests/voice-engine-demo.html`은 실제 생성된 `integration/game.html`을 별도 세이브로 실행하는 검증 장면이며 전체 163명을 선택할 수 있습니다. 로컬 화면에서 세린의 미소·분노, 세레나 여왕의 중후 여성 음색, 주민 에다의 어린 여성 음색, 음색 변경, 음소거를 확인했습니다. `tests/battle-demo.html`의 ‘몬스터 음향 전투 검증’에서 늑대 공격·피격·HP 0 쓰러짐 재생을 확인했습니다. 이 전투는 별도 세이브의 검증용 수치를 쓰며 실제 판정이나 원래 NPC 수치를 바꾸지 않습니다. `tests/monster-voices-preview.html`은 몬스터 20종의 공격·피격·쓰러짐을 듣는 화면입니다. 실제 ChatGPT/Tampermonkey 세션에서의 장기 플레이는 검증하지 않았습니다.
