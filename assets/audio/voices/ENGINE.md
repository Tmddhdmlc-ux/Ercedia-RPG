# 게임 엔진 연결

실제 장면의 현재 화자와 표정으로 짧은 비언어 리액션을 재생합니다. 대사 전체를 읽는 TTS는 아닙니다. `speaker_id`가 있으면 해당 인물을 우선하고, 여러 인물 장면은 각 인물의 표정을 따로 이어받습니다. 나레이션·전투 대사는 자동 성우 대상에서 제외합니다. 전투는 기존 스킬·타격 음향을 사용합니다.

세린은 `female_young`입니다. 나머지 기본 음색은 `characters/npc_roster_100.json`의 명시적인 외모란 성별·나이를 사용합니다. 30세 미만은 어린 스타일, 그 이상은 중후 스타일로 분류하는 음향 편집 기준이며, 배우의 실제 연령을 뜻하지 않습니다. 명시된 정보가 없는 인물은 추측해서 배정하지 않습니다. `tampermonkey/voice-build.mjs`가 레지스트리를 번들용 `web/voice-data.js`로 생성합니다.

게임 상단 ‘성우 리액션’에서 현재 화자의 네 가지 음색, 음량, 켜기/끄기를 선택합니다. `uiPreferences.voice`에 저장하고 복원합니다. BGM도 `uiPreferences.music`에 저장하므로 임베디드 저장 브리지에 음향 설정만 써서 전체 게임 데이터를 덮어쓰지 않습니다.

첫 사용자 입력 이후 재생합니다. 화면 갱신으로 같은 대사를 반복 재생하지 않으며, 대사를 넘기거나 음소거하거나 지도·타이틀·전투로 전환하거나 탭을 숨기면 이전 음성 및 지연된 로딩을 취소합니다.

`tests/voice-engine-demo.html`은 실제 생성된 `integration/game.html`을 별도 세이브로 실행하는 검증 장면입니다. 로컬 화면에서 여성 어린 음색의 미소·분노, 중후 음색 변경, 음소거를 확인했습니다. 실제 ChatGPT/Tampermonkey 세션에서의 장기 플레이는 검증하지 않았습니다.
