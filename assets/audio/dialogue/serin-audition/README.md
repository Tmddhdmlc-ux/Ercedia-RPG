# 세린 · 다섯 대사 목소리 후보

첫 만남·걱정·전투 시작·궁극기·승리의 한국어 음성 시안이다. Microsoft Edge 온라인 TTS의 ko-KR-SunHiNeural을 edge-tts로 사용했다. 기존 외부 반응음의 성우와 동일 인물이 아니며, 목소리 복제를 사용하지 않았다. 감정 지시로 성우 연기를 생성하는 서비스가 아니라 말속도와 높이를 조절하는 합성음이므로 실제 감정 연기라고 주장하지 않는다.

최종 MP3, 원본 합성음(source/), 대사·상황별 속도/높이·SHA-256(lines.json)을 보관한다. 65 Hz 이하를 정리하고 -18 LUFS/-1.5 dBTP 기준으로 음량을 맞췄다. 음악·효과음·공간 잔향은 섞지 않아 목소리 자체를 비교한다. 대사 내용은 생성 서비스로 전송해 음성으로 제작한다.

미리보기: tests/serin-dialogue-preview.html. 다섯 대사 연속 또는 개별 재생을 제공한다. 목소리 선택 전 시안이므로 실제 게임, 궁극기 컷씬, 기존 반응음 은행에는 연결하지 않았다. 대사가 현재 스킬의 습득·실전 사용을 의미하지 않는다.

재생성: Python에 edge-tts와 imageio-ffmpeg를 설치한 후 `python tools/build-serin-lines.py`. 음성 생성은 온라인 서비스 상태에 의존한다. 도구: https://github.com/rany2/edge-tts . 생성 음원은 CC0 외부 에셋으로 표기하지 않는다.
