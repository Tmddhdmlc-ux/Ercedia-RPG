# 에르세디아 BGM

승인한 마을·전투곡을 기본 적용하고 밤·국경·왕실·극동·미탐색·보스 테마를 추가했다. Background Music 도구가 반환한 AI 생성 워터마크 포함 MP3를 원본으로 보관한다. 국경·왕실·극동은 이번 요청에서 새로 생성했고 나머지는 기존 AI 라이브러리 선택이다. tracks.json에 곡마다 출처·길이·템포·조성 힌트를 기록했다. 밤곡은 솔브린의 아침을 직접 편곡한 음원이 아니라 따뜻하고 잔잔한 분위기의 별도 곡이다.

게임 첫 신뢰할 수 있는 클릭/키 입력에서 기본 재생한다. BGM 메뉴에서 꺼짐·음량·곡 선택을 저장하고 다음 실행에도 기억한다. 기본 음량은 22%, 최대 70%다. 자동 모드는 실제 장면의 장소와 배경을 사용한다. 지도 표식 선택은 이동이 아니므로 곡을 바꾸지 않는다. 전투가 우선이고 비전투에서는 국경 검문소, 왕궁 회랑/왕실, 극동, 미탐색·미개척 장소를 구분한다. 일반 마을은 장면의 time 또는 gameState.time에 밤·심야·새벽 또는 18:00~05:59가 명시되면 밤곡을 쓴다. 컴퓨터 시각은 사용하지 않는다. 장소·시간이 없는 상태는 마을곡으로 돌아간다.

보스 식별 항목이 현재 장면 스키마에 없으므로 보스곡은 BGM 메뉴에서 직접 선택한다. 적의 능력치만으로 보스를 추측하지 않는다. 스키마 v1과 저장 버전은 유지한다.

tests/music-preview.html에서 여덟 곡을 재생·다운로드한다. web/background-music.js는 반복에 1.2초 겹침, 전환에 0.8초 페이드를 사용한다. 곡을 한 번 미리 예약하고 전투 속도는 BGM 속도를 바꾸지 않는다. 정지와 다운로드가 겹쳐도 뒤늦게 재생하지 않는다. 원본 자체가 완벽한 루프로 작곡됐다고 주장하지 않는다. 미리보기와 게임은 독립 플레이어이므로 동시에 켜면 소리가 겹친다.

로컬 미리보기에서 음원 디코딩·재생 상태와 전환을 확인한다. 실제 ChatGPT/Tampermonkey 실행 검증은 별도다.
