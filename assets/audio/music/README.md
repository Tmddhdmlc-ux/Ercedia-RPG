# 에르세디아 BGM

승인한 마을·전투곡을 기본 적용하고 밤·국경·왕실·극동·미탐색·보스 테마를 추가했다. Background Music 도구가 반환한 AI 생성 워터마크 포함 MP3를 원본으로 보관한다. 국경·왕실·극동은 이번 요청에서 새로 생성했고 나머지는 기존 AI 라이브러리 선택이다. tracks.json에 곡마다 출처·길이·템포·조성 힌트를 기록했다. 밤곡은 솔브린의 아침을 직접 편곡한 음원이 아니라 따뜻하고 잔잔한 분위기의 별도 곡이다.

게임 첫 신뢰할 수 있는 클릭/키 입력에서 기본 재생한다. BGM 메뉴에서 꺼짐·음량·곡 선택을 저장하고 다음 실행에도 기억한다. 기본 음량은 22%, 최대 70%다. 자동 모드는 실제 장면의 장소와 배경을 사용한다. 지도 표식 선택은 이동이 아니므로 곡을 바꾸지 않는다. 전투가 우선이고 비전투에서는 국경 검문소, 왕궁 회랑/왕실, 극동, 미탐색·미개척 장소를 구분한다. 일반 마을은 장면의 time 또는 gameState.time에 밤·심야·새벽 또는 18:00~05:59가 명시되면 밤곡을 쓴다. 컴퓨터 시각은 사용하지 않는다. 장소·시간이 없는 상태는 마을곡으로 돌아간다.

보스 식별 항목이 현재 장면 스키마에 없으므로 보스곡은 BGM 메뉴에서 직접 선택한다. 적의 능력치만으로 보스를 추측하지 않는다. 스키마 v1과 저장 버전은 유지한다.

tests/music-preview.html에서 아홉 곡을 재생·다운로드한다. web/background-music.js는 반복에 1.2초 겹침, 전환에 0.8초 페이드를 사용한다. 곡을 한 번 미리 예약하고 전투 속도는 BGM 속도를 바꾸지 않는다. 정지와 다운로드가 겹쳐도 뒤늦게 재생하지 않는다. 원본 자체가 완벽한 루프로 작곡됐다고 주장하지 않는다. 미리보기와 게임은 독립 플레이어이므로 동시에 켜면 소리가 겹친다.

로컬 미리보기에서 음원 디코딩·재생 상태와 전환을 확인한다. 실제 ChatGPT/Tampermonkey 실행 검증은 별도다.

## 타이틀 · 에르세디아의 서막

약 2분 58초의 타이틀 테마를 Background Music (Lyria)의 기존 AI 생성 라이브러리에서 선택했다. 새로 생성된 곡이라고 주장하지 않는다. AI 생성 워터마크가 포함되어 있으며 원본 MP3와 SHA-256, 요청한 스타일, 도구의 템포·조성 힌트는 tracks.json에 기록한다. 실제 악기 구성과 구조는 요청한 스타일과 다를 수 있다.

자동 BGM 모드는 타이틀과 캐릭터 생성이 진행 중인 모든 단계에서 title을 우선한다. 이름·성별·문답·기질·왕국 및 시작 지역 확정까지 같은 곡을 끊지 않는다. 생성 중 저장을 이어가도 유지하며, 새 캐릭터 생성 완료 또는 이미 완료된 게임 이어하기 후에는 전투·장소·게임 시간에 맞는 기존 곡으로 전환하고 타이틀 복귀 시 title로 돌아간다. 음소거·음량과 직접 선택 설정은 그대로 존중한다. 브라우저 정책에 따라 첫 사용자 입력 이후 재생하며, 게임 화면의 실제 ChatGPT/Tampermonkey 실행 검증은 별도다.
