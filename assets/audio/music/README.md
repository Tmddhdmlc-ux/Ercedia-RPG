# 마을·전투 BGM 1차 시안

연결된 Background Music 도구에 마을과 전투 스타일을 각각 요청했다. 도구는 신규 생성 대신 기존 AI 생성 라이브러리에서 가까운 곡을 반환했다(source=library). 이번 요청에서 직접 작곡한 곡이나 새로 생성한 곡으로 표시하지 않는다. 도구 설명에 따라 Lyria AI 생성 워터마크가 포함된 원본 MP3를 저장했다.

- village_v1.mp3 — 솔브린의 아침, 길이 힌트 158초
- battle_v1.mp3 — 칼날의 공방, 길이 힌트 182초
- tracks.json — 요청 스타일과 도구가 제공한 템포·조성 힌트. 전투 요청 템포와 반환 힌트는 다르며 실제 청취 평가가 필요하다.

tests/music-preview.html에서 두 곡을 각각 재생·다운로드한다. 게임 안 BGM 메뉴에서 켜기, 자동/마을/전투, 음량을 선택한다. 기본은 꺼짐이며 음량 22%다. 자동 모드는 전투 진입 시 전투곡, 종료 시 마을곡으로 전환한다. 두 곡만 준비된 시안이므로 다른 지역에도 자동 모드의 비전투 기본곡은 마을곡이다.

web/background-music.js가 1.2초 겹침으로 반복하고 전환은 0.8초 페이드한다. 곡을 한 번 미리 예약하므로 짧은 타이머에 의존하지 않는다. 전투 속도 변경은 BGM 속도를 변경하지 않는다. 원본 음원 자체가 매끄러운 루프로 작곡됐다고 주장하지 않는다. BGM 정지와 오래 걸린 다운로드가 겹쳐도 뒤늦게 재생하지 않는다.

게임 화면과 별도 미리보기는 독립 플레이어다. 동시에 두 화면에서 재생하면 겹칠 수 있으므로 비교 시 한 화면의 BGM을 정지한다. 실제 ChatGPT/Tampermonkey 실행 검증은 별도다.
