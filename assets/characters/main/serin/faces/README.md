# 세린 공통 얼굴 표정 9종

사용자 요청에 따라 복장과 독립된 얼굴 레이어로 제작했다. 기본 표정은 사용자가 선택한 세린 전신 원화에서 추출했다. 표정 8종은 같은 얼굴 참조로 생성한 뒤 고정 머리카락 부분을 기준으로 정렬하고 같은 윤곽으로 잘랐다.

- 512×512 RGBA PNG, 9종 동일 알파 마스크·캔버스·앵커. 목·갑옷·복장은 포함하지 않는다.
- base, smile, angry, surprised, sad, embarrassed, afraid, annoyed, love.
- love는 하트 눈 없이 자연스러운 애정 표정이다.
- 비교: preview.png / 위치·검증 기록: manifest.json.
- 독립 얼굴 자산이며 복장별 합성·UI 적용은 이번 작업 범위가 아니다. 복장과 결합할 때 얼굴 각도·크기·경계 마스크를 맞춰야 한다. 이 레이어만 교체한다고 임의의 복장에 자동으로 들어맞는 것은 아니다.
- 기존 반신 초상화와 standing/base.png는 변경하지 않았다.
