# 세린 궁극기 컷신 시안

`ultimate-flash-v1.png`는 사용자가 선택한 비장한 표정·온몸의 빛·검광·배경을 포함한 불투명 가로 일러스트다. 기존 승인 스탠딩/초상화를 교체하지 않는다. 새 기술명·스킬 보유·경지·수치를 확정하지 않는다.

재생 화면: `/tests/serin-ultimate-preview.html`

- 리마스터: 암전·검광 응축 0–0.45초, 사선 얼굴 컷인 0.45–1.45초, 전체 컷신 1.45–3.45초, 섬광·타격 3.45초, 전투 복귀 3.9–5초. 오른쪽 아래 기술명은 ‘결의의 일섬’이며 전신 개방부터 타격 후까지 표시한다.
- 원본 일러스트는 보존하고 화면의 사선 마스크·카메라 확대·레터박스·Canvas 검광과 입자로 연출한다. 재생 시간 기준으로 계산하므로 일시정지·배속·다시보기에도 동일한 흐름을 유지한다.
- 참고: [Tales of Arise 공식 비오의/컷인 설명](https://toarise.tales-ch.jp/flg/system/battle.html). 다른 게임의 이미지·음원·영상 자산은 사용하지 않는다.
- 같은 그림에서 CSS로 얼굴 구간을 확대한다. 이미지 원본을 잘라 덮어쓰지 않는다.
- 최신 등록 타격음을 재사용하며 일시정지·건너뛰기·다시보기·배속·전체화면·약한 섬광 제공.
- 실제 전투/ChatGPT 브리지/세이브/보상에 연결하지 않은 연출 미리보기다. 브라우저 시각 확인은 사용자에게 맡긴다.

Built-in image_gen으로 생성했다. 최종 생성 지시: 기존 세린의 얼굴·금발 포니테일·푸른 눈·은백색 금장 갑옷·남색 망토를 유지하고, 측면에서 힘을 쏟는 비장한 표정, 전신에서 방출되는 백금색 빛과 거대한 검광, 어두운 전장 배경을 포함한 16:9 애니메이션풍 컷신. 글자·UI·추가 인물 없이 한 장으로 제작.
