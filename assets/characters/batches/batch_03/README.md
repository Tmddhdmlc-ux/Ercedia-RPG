# batch_03 — 기본형 시안

범위 21~30. 10명 중 기본형 세트 완료 10명. 상세 ID·파일·알파·여백·해시·제작 프롬프트는 manifest.json 및 prompts.json.
사용자 일괄 제작 지시에 따른 신규 아트 자산이다. 최종 디자인 승인 대기이며 기존 세린·세계관·게임 브리지는 수정하지 않는다. 마수는 인간 전신 규격을 강제하지 않고 투명 초상화로 제작한다. 인간 전신은1024×1536, 초상화는1086×1448, 마수 초상화는1024×1024 RGBA. 생성 픽셀은 종횡비를 유지하여 캔버스·여백만 정리했다. 표정·복장 파생은 미제작.

반복 등장 후보: 해당 배치의 사회 인물. 구체적 우선순위는 플레이·사용자 검수 이후 결정한다. 미정 외형의 세부 색·복식·장식은 시안이며 새 캐논으로 자동 확정하지 않는다.
