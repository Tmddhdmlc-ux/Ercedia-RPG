# NPC 아트 1차 배치 — 검수 대기

사용자 지시서 v1.0에 따른 ER-NPC-001~010 기본형 시안. 총 10명, 전신 10장과 초상화 10장이다. 정식 디자인 승인과 본편 장면 JSON의 NPC 연결은 아직 진행하지 않았다. 기존 세린·지도·게임 상태는 수정하지 않았다.

- 전신: assets/characters/standings/[ID]/base.png — 1024×1536 RGBA.
- 초상화: assets/characters/portraits/dialogue/[ID]/base.png — 1086×1448 RGBA.
- 명부·외형·소속·계급: characters/npc_roster_100.json 2.0-growth-rebalance. 작업 중 재조정된 능력치는 변경하지 않았다. 이미지에 숫자를 쓰지 않는다.
- 시트: characters/[ID].md. 정설과 구도/복식 디테일 제안을 구분했다.
- 제작: 내장 imagegen, 자산마다 개별 생성. 전신 기준에 맞춰 비율 유지 축소·캔버스 정렬을 수행했고, 케른의 좌안 흉터 방향을 위해 초상화·전신을 함께 반전했다. 생성 원본은 별도 로컬 보관.
- PNG 20장 RGBA·크기·알파 확인. 전신 사방 각각 최소 5% 이상, 무기·망토·발끝 포함. 측정값과 해시는 manifest.json.
- 로컬 브라우저에서 10명 모두 초상화/전신 로딩과 대화 구도 전환, 세린 비교를 확인했다. 일반 게임 UI 및 ChatGPT 런처의 NPC 장면 등록은 아직 하지 않았다. 모바일 실제 기기 검수는 미실시.
- 같은 기사단은 소속 색과 문장 모티브를 공유한다. 팔짱·허리 손·방패·고글·뒷짐·벨트 손·손목 잡기 등의 자세와 얼굴 각도를 구별했다.
- 세부 문장 형태/좌우 해석, 페이·다리오의 나이 인상, 기본 기사 복식의 장식량은 사용자 검수 항목이다. 세부 장비 디자인을 공식 정설로 자동 확정하지 않는다.
- base만 제작. 반복 등장 후보 10명은 manifest.json에 기록했으며 중요도와 추가 표정은 사용자 검수 후 결정한다.
