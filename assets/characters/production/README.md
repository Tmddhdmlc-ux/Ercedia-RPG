# 캐릭터·문장 아트 제작 목록

신규 roster 100명과 핵심 인물 38명의 **기본형 시안**. 공식 디자인 승인 대기(`review_pending`). 세린 승인 원화와 기존 게임 장면은 유지한다.

| 대상 | 구성 | PNG 수 |
|---|---|---:|
| roster 인간 80명 | 초상화 + 전신 스탠딩 | 160 |
| roster 마수 20종 | 투명 초상화 | 20 |
| 핵심 인물 38명 | 초상화 + 전신 스탠딩 | 76 |
| 왕국 3국·영주령 13곳 | 국기·영주 깃발 | 16 |
| 문장이 명시된 세력 8곳 | 투명 문장 | 8 |
| 합계 | 기존 1차 20장 포함 | 280 |

이번 후속 작업에서 추가한 PNG는 260장이다. 명단 기준 모든 대상의 base를 제작했으며, 각 캐릭터의 이름·ID·소속·파일 경로는 [catalog.json](catalog.json)에 기록했다. 추가 표정 후보도 이 목록에 있으며 현재 파일은 base만 존재한다.

## 확인 화면

[전체 아트 검수 화면](../../../prototypes/npc_art_library.html)은 저장소 루트에서 정적 서버로 실행한다. 예: `http://127.0.0.1:4184/prototypes/npc_art_library.html`.

캐릭터를 고르면 전신과 초상화를 함께 볼 수 있다. `대화 구도`, `전신 확인`, `세린과 비교`로 크기와 잘림을 확인한다. 마수는 초상화 중심으로 표시한다. 국기·깃발·문장은 별도 탭에서 확인한다. 검수 화면은 게임 브리지 및 저장 데이터와 연결하지 않았다.

## 기준과 규격

- 외형·소속: `characters/npc_roster_100.json`, `characters/core_cast_stats_38.json`, `KINGDOMS.md`, `LORDSHIPS.md`, `FACTIONS.md`.
- 화풍: 세린 승인 초상화와 전신을 참조한 2D 카툰·애니풍 중세 판타지.
- 전신: 1024×1536 RGBA. 인물·무기·망토 포함, 사방 최소 약 5% 여백, 발끝 앵커 일치.
- 인간 초상화: 1086×1448 RGBA. 마수 초상화·세력 문장: 1024×1024 RGBA.
- 국기·영주 깃발: 1536×1024 RGBA. 문장의 원문 구성 요소를 반영하되 미지정 구도·색·장식은 디자인 제안이다.
- 각 배치 manifest에는 투명도, 해상도, 여백, 앵커와 SHA-256을 기록했다. prompts.json에는 제작 지시를 보존했다.

## 검증과 범위

[validation.json](validation.json)에 각 PNG의 로컬 검사와 불변 커밋 URL에서 받은 실제 이미지의 해시·투명도 검사 결과를 기록한다. 디자인 대조와 비교 시트 검수도 수행했다. 성인 나이 표현과 작은 문장·흉터의 가독성 등 미술 판단은 최종 사용자 검수 대상이다.

새 표정·복장, 배경·아이템 및 문장이 미정인 세력의 임의 로고는 이 제작 목록에 포함하지 않는다. 게임의 세계관, 능력치, 국가 경계, NPC 장면 자동 등록은 변경하지 않았다. 실제 ChatGPT/Tampermonkey 20턴 실행 시험은 수행하지 않았으며 성공으로 기록하지 않는다.

## 엔진 연결 승인 — 2026-10-09

사용자가 전체 아트를 칭찬하고 게임엔진 연결·위치 지정을 요청하여 이번 기본형의 엔진 사용을 승인했다. 초기 생성 기록의 review_pending은 제작 당시 이력이며 현재 런타임 등록은 characters/art_registry.json을 따른다. 세린 포함 139명의 기본 활동 거점은 characters/npc_placements.json에 등록했다. 새로운 표정·복장 제작과 설정 밖 지점·국경 확정은 포함하지 않는다.
