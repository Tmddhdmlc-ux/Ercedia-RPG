# 2. 전체 아트 스타일 통일

기존 에르세디아 RPG의 세린 캐릭터와 비주얼노벨 UI를 시각적 기준으로 삼는다.

### 기본 아트 방향
- 고품질 2D 카툰풍·애니풍
- 선명하고 깔끔한 선화
- 세밀하지만 지나치게 복잡하지 않은 디테일
- 중세 판타지 세계관에 어울리는 색감
- 과도하게 사실적인 3D 렌더링 지양
- 모든 결과물이 하나의 게임에서 제작된 것처럼 통일

장비·책·재료는 **인벤토리에서 작은 크기로 표시되어도 구분이 가능해야 한다.**

장소 배경은 캐릭터 스탠딩이 전면에 표시되는 비주얼노벨 구조를 고려한다.

# 3. 장비 300종 — 템플릿 기반 제작

## 제작 수량

- 검 90종
- 스태프 90종
- 방어구 60종
- 악세사리 60종

**모든 장비를 각각 처음부터 그리지 않는다.**

### 3-1. 기본 아이템 템플릿

우선 아래 형태별 기본 원형을 제작한다.

**검 템플릿**
- 일반 직검
- 장검
- 세검
- 대검
- 곡선형 검
- 의장용 검

**스태프 템플릿**
- 목재형
- 금속형
- 수정형
- 자연목형
- 마도공학형
- 고대유물형

**방어구 템플릿**
- 가죽갑옷
- 경량 판금갑
- 중갑
- 로브
- 전투복
- 의식용 방어복

**악세사리 템플릿**
- 반지
- 목걸이
- 펜던트
- 부적
- 귀걸이
- 마나 장식품

각 원형을 바탕으로 색상, 재질, 문양, 장식, 실루엣을 변경하여 실제 장비 ID에 대응하는 최종 아이콘을 제작한다.

템플릿의 차이는 명확해야 하지만, 같은 계열 장비끼리 스타일 일관성을 유지한다.

## 3-2. 등급별 표현

| 등급 | 대표 색상 | 표현 |
|---|---|---|
| 하급 | 회색 | 낡은 재질, 단순한 장식 |
| 중급 | 녹색 | 튼튼한 재질, 정돈된 디자인 |
| 고급 | 파랑 | 세공된 장식, 세련된 광택 |
| 유니크 | 보라 | 희귀 재질, 고유 문양 |
| 에픽 | 금색 | 독특한 실루엣, 고급 마법 효과 |

**등급색은 아이콘 테두리나 작은 광륜에 반영한다.**

아이템 자체의 색상은 원본 설정을 우선한다. 모든 고급 검을 무조건 파란색 검으로 만들지는 않는다.

유니크와 에픽은 단순 색상 차이만 두지 말고 고유한 외형적 특징을 추가한다.

## 3-3. 아이콘 규격

- PNG
- 투명 배경
- 권장 512×512
- 아이템 중앙 배치
- 그림자와 광원 방향 통일
- 읽을 수 없는 문자를 아이템 표면에 과도하게 생성하지 않을 것

저장 경로:

`assets/items/equipment/{ER-EQ-ID}.png`

300개 장비 ID와 최종 이미지 경로가 모두 일치해야 한다.

# 4. 몬스터 전리품 40종

원본 파일:
`items/loot_tables_monsters_dungeons.json`

마수 20종에서 얻을 수 있는 일반·희귀 전리품 총 40종을 제작한다.

### 제작 방식

모든 전리품을 별도 예술 작품처럼 복잡하게 제작할 필요는 없다.

재료 유형별 템플릿을 활용한다.

- 가죽·털
- 발톱·뿔·엄니
- 비늘·갑각
- 수정·보석
- 마나핵·마나기관
- 특수 가루·액체

이 템플릿을 기반으로 실제 마수의 특징을 반영한다.

예를 들어 서리갈기 가죽은 차가운 은회색, 진동 수정낭은 청보라 수정질, 마나 균열 심석은 이질적인 마나 균열이 드러나야 한다.

### 규격
- 512×512 PNG
- 투명 배경
- 작은 아이콘에서도 소재 구분 가능

저장 경로:

`assets/items/materials/{MAT-ID}.png`

# 5. 검술서 30권·마술서 40권 — 최우선 간소화

**이 부분은 개별 책 70권을 하나하나 이미지 생성하지 않는 것을 원칙으로 한다.**

## 5-1. 책 템플릿

먼저 두 종류의 기본 템플릿을 제작한다.

- 검술서 기본 책
- 마술서 기본 책

이후 등급 색상만 바꾼다.

### 등급 색상

| 등급 | 책 표지색 |
|---|---|
| 하급 | 갈색·회색 |
| 중급 | 녹색 |
| 고급 | 파란색 |
| 유니크 | 보라색 |
| 에픽 | 금색 |

**최소 기본 책 디자인은 2종 × 5등급 = 10개다.**

## 5-2. 표지 심볼

검술서에는 검 모양의 상징을 사용한다.

마술서에는 마법진 형태의 공통 상징을 사용한다.

추가로 필요하다면 마술서에 여섯 속성의 심볼을 사용한다.

- 화염
- 물
- 바람
- 전기
- 어둠
- 빛

단, 이미지 생성 횟수를 줄이는 것이 목적이므로 심볼은 별도의 투명 PNG 또는 SVG 형태로 제작하여 책 템플릿 위에 합성한다.

70권의 아이콘은 공통 템플릿에서 자동 생성한다.

긴 책 제목이나 작은 글씨를 이미지 내부에 생성하지 않는다. 책 이름은 게임 UI에서 텍스트로 표시한다.

### 규격
- 512×512 PNG
- 투명 배경

저장 경로:

`assets/items/books/{BOOK-ID}.png`

최종적으로는 70개 책 ID 모두가 이미지 파일을 갖도록 하되, 생성형 이미지 모델을 70번 호출하는 방식은 사용하지 않는다.

## 6-2. 재사용 원칙

261개 슬롯을 전부 독립 이미지로 생성할 필요는 없다.

다음 조건에서 재사용을 허용한다.

- 동일한 실제 건물에 여러 조직이 입주한 경우
- 같은 시설 내부를 다른 기능으로 방문하는 경우
- 같은 던전의 연결된 복도 중 외형이 거의 동일한 경우
- 일반 여관이나 시장 등 공용 배경으로 충분한 경우

하지만 지역별 대표 전경, 핵심 시설, 독특한 보스방은 별도의 아트를 우선한다.

재사용할 때는 **어떤 장소 ID가 어느 이미지 파일을 사용하는지 명시적인 매핑**을 저장한다.

단순히 서로 다른 장소에 아무 배경이나 돌려 쓰지 않는다.

### 배경 규격

- 가로형 PNG
- 권장 1536×1024 이상
- 기존 세계지도는 수정하지 않음
- VN 하단 대화창을 고려한 구도
- 스탠딩과 주요 배경 요소가 겹치지 않도록 배치

# 8. 장시간 작업을 위한 운영 규칙

이 프로젝트는 이미지가 매우 많으므로 한 번에 모든 파일을 메모리에 올리거나 한 번에 GitHub에 대량 업로드하지 않는다.

**20~30개 자산 단위로 제작·검증·커밋**하는 것을 권장한다.

각 배치마다 다음 사항을 기록한다.

- 대상 ID
- 완료 ID
- 미완료 ID
- 제작 실패 이유
- 현재 이미지 파일 경로
- 적용한 템플릿
- GitHub 커밋 SHA

작업 현황은 다음 파일로 관리한다.

`assets/ART_PRODUCTION_PROGRESS.md`

작업 중단 후 다시 시작하면 반드시 이 파일과 실제 GitHub 저장 상태를 비교하여 이어서 작업한다.

이미 완료한 자산을 불필요하게 다시 생성하지 않는다.

이미지 생성이 실패하거나 작업 한도에 도달했다면 완료했다고 주장하지 말고 마지막 성공한 배치와 남은 작업을 보고한다.

# 10. 최종 목표

에르세디아 RPG의 장비·전리품·기술서·장소 배경을 일관된 시각적 품질로 제작하여 GitHub에 등록한다.

**작업 효율 원칙**

- 장비: 기본 형태 템플릿 + 등급별 변형
- 전리품: 재료 유형 템플릿 + 마수별 특징
- 검술서·마술서: 공통 책 템플릿 + 등급색 + 심볼
- 장소 배경: 개별 환경 디자인 + 적절한 재사용

파일 경로와 이름은 반드시 기존 GitHub 데이터의 고유 ID를 기준으로 한다.

불필요한 재작업과 이미지 생성 호출을 줄이고, 완성된 자산부터 순차적으로 GitHub에 저장한다.

**작업 시작 후 불필요한 질문 없이, 기존 확정 설정에 따라 자율적으로 진행한다.**

세계관이나 게임 규칙을 변경해야 하는 문제가 발생하면 임의로 수정하지 말고 해당 항목을 보류하고 보고한다.
## 최신 추가 확정 — 아이템 희귀도 테두리

이 지시서의 아이콘 테두리/등급 광륜 언급보다 사용자 추가 확정 [ITEM_RARITY_RULES.md](../ITEM_RARITY_RULES.md)가 우선한다.
원본 PNG에는 희귀도 테두리를 합성하지 않는다. 하급 #FFFFFF / 중급 #26B75A / 고급 #3489FF / 유니크 #A35CF0 / 에픽 #E64444를 UI에서 rarity에 따라 표시한다.
책 표지와 장비 자체의 기존 디자인은 유지한다. 유니크/에픽 발광은 UI에서 은은하게만 허용한다.
