# 워크 2 이미지 제작 최종 검수

총 671개 슬롯을 제작·저장·개별 시각 검수했다. 장비 300개, 전리품 40개, 책 70개, 장소 261개다.

- 전체 PNG를 실제로 디코딩하고, 원본 데이터의 ID·이름·희귀도·경로와 대조했다.
- 아이콘 410개는 512×512 RGBA이며 실제 투명 영역과 안전 여백을 확인했다. PNG에는 등급 테두리를 합성하지 않았다.
- 장소는 1536×1024 이상이다. 공용 전투 전환 효과 `IMG-SHARED-11`만 RGBA이며, 중앙이 투명하다. 나머지 장소는 RGB다.
- 장소 재사용 28건은 동일 실제 장소의 명시적 매핑이며 원본·대상 파일 해시가 일치한다. [재사용 매핑](background-reuse-map.json)을 참조한다.
- 671개 파일 모두 GitHub main의 Git 파일 내용과 일치하며, 모든 이미지 커밋이 main에 포함됨을 확인했다. 각 분야와 장소 유형을 포함한 원본 HTTP 참조 13건도 200 응답과 해시 일치를 확인했다. [기계 검수 기록](final-audit.json)을 참조한다.
- 제작 배치 커밋이 기존 프로젝트 PNG를 변경하지 않았음을 확인했다. 다른 작업에서 추가한 캐릭터·UI 변경은 보존했다.
- 최신 게임 코드 자동 검사 140개가 통과했다. integration/version.json은 2.1.0, 기존 integration/assets.json을 확인하고 빌드를 실행했다. 신규 장소 261개를 시작 시 일괄 다운로드하도록 추가하지 않았다.

## 실제 VN 샘플 확인

실제 index.html, web/app.js, web/style.css를 사용한 별도 검수 페이지에서 영주령 전경 `IMG-W1-OVERVIEW`, 시설 내부 `IMG-FAC-E2-01-INTERIOR`, 공용 여관 `IMG-SHARED-01`, 결과 배경 `IMG-SHARED-12`, 투명 전환 효과 `IMG-SHARED-11`을 확인했다. 저장 상태는 검수용 메모리 안에서만 유지하며 사용자 세이브를 변경하지 않았다.

1280×720 브라우저에서 배경 원본은 1536×1024로 정상 로드되고 세린·대화창과 함께 표시된다. 전환 효과는 중앙을 가리지 않는다. [실제 화면](vn-live-sample.png)을 참조한다.

현재 VN의 `object-fit: cover`는 넓고 낮은 장면 영역에서 원본 위아래를 자른다. 특히 W1 전경의 높은 건물 일부가 잘리는 것을 확인했다. 원본 PNG는 잘리지 않았으며, UI 연결 시 장면별 배경 정렬 또는 전체 표시 모드를 결정해야 한다. 모든 화면에서 잘림이 없다는 검증으로 기록하지 않는다.

## UI 연결 범위

아이콘은 기존 아이템 데이터의 icon_path와 아이템 이미지 목록에 등록했다. rarity 공통 색상은 하급 #FFFFFF / 중급 #26B75A / 고급 #3489FF / 유니크 #A35CF0 / 에픽 #E64444다. 에픽 책의 금색 표지는 유지하며 UI 테두리는 빨강이다. 전리품에 원본 rarity가 없는 경우 등급을 임의 생성하지 않는다.

장소 261개는 기존 location_image_manifest.json의 정확한 ID·경로·상태와 전체 제작 목록으로 제공한다. 현재 게임 장면 스키마가 자동으로 261개 장소 배경을 선택하도록 확장하는 UI 기능 개발은 이번 이미지 제작 범위에 포함하지 않았다. 검수 샘플의 배경 선택 기능은 검수 페이지 전용이다.

실제 ChatGPT/Tampermonkey 실행, 20턴 플레이, 업데이트 시나리오는 검증하지 않았다.
