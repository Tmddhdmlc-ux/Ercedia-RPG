# 3국 지리 배치 시안 v0.1 — 승인 전

**지형 배치·국경·영주령 행정 경계는 시안이며 미확정이다.** 왕국·영주령 이름과 영주는 최신 KINGDOMS.md·LORDSHIPS.md 및 map_locations.json을 따른다. 왕도 도시명과 써니 빌리지 위치는 미정이다.

## 최신 영주령 UI 갱신 — 2026-10-08
메인 지도 배너를 벨로아·드라켄·루메린으로 갱신했다. 지형 원본 world_base.png와 map_locations.json의 좌표는 변경하지 않았다. 확대 화면의 영주령 이름은 짧게 표시하고 클릭 상세 창과 목록에서는 13개 정식 영주령 이름·영주·공개 경제·지형·인구·전력을 제공한다. 왕도는 왕실 직할 중심으로 별도 표시하고 후보 시설의 소유권은 확정하지 않는다. 비밀·실제 야망·사건 배후는 지도 메뉴에 노출하지 않는다.

브라우저에서 13개 영주령 클릭, 전체 지도 핀 클릭, 지역 확대, 대화 탭 복귀 상태 유지와 생성된 integration/game.html의 지도 클릭을 확인했다. 국경·행정 경계는 그리지 않았다. 단위 테스트 19개 통과. 런처/브리지/저장/장면 스키마 v1을 유지하고 integration 업데이트 묶음을 생성했다. 실제 ChatGPT에서의 Tampermonkey 업데이트 적용·20턴 플레이는 이번 지도 검수에 포함하지 않았다. 아래 초기 제작 기록은 당시 시안 이력이다.

## 메인 지도 표시 선택 — 2026-10-08
사용자가 클릭 위치 가이드 지도를 메인 표시 기준으로 선택하고 설명 지도의 지역명을 사용하도록 요청했다. `world_main.png`는 같은 지형과 동일한 클릭 좌표를 유지하면서 얇은 지역명 배너와 성·왕관·닻·위험 표식을 적용한 표시용 이미지다. `world_main_overlay.png`는 그 안내만 분리한 투명 레이어이고 `main_map_presentation.json`에 표시 자산을 기록했다. 게임 UI 연결 기록은 아래 게임 UI 반영 항목을 참고한다. 표시 방식 선택은 지리·국경·공식 국명 확정을 의미하지 않는다.

## 파일

### 게임 UI 반영 — 2026-10-08
저장소 루트 `index.html` 세계지도 화면에 `world_main.png`를 연결했다. 지역 표식이나 지역 버튼을 누르면 해당 지역으로 확대되고 등록된 세부지점 목록이 보인다. 전체 지도에서 지점 표식을 누르면 그 지점의 소속 지역으로 확대한다. 확대된 화면의 지점 표식·목록을 누르면 설명과 선택 강조를 갱신하며 `전체 지도` 버튼으로 돌아온다. `map_locations.json`의 지역 7곳·지점 24곳과 주변 군도를 사용하고 이미지와 클릭 영역을 같은 좌표·변환으로 표시한다. 대화 복귀·전체화면·선택과 확대값 저장을 지원한다. 확대 기능은 `web/map-camera.js`, 클릭 연결은 `web/app.js`에 구현되어 있다. PNG 자체나 GitHub 파일 미리보기에는 클릭 기능이 없으며 저장소 루트에서 `node server.mjs`로 실행한다. 초기 `prototypes/low_lag_vn_v03.html`에는 최신 확대 기능이 없다. 실제 이동 기능은 아직 연결하지 않았다. 표시 연결은 지리·국경·국명·써니 빌리지 위치 확정을 의미하지 않으며 원본 PNG는 변경하지 않았다. 브라우저 최종 확인은 사용자가 직접 진행한다.
- world_base.png: 내장 이미지 생성 도구로 기존 초안을 수정한 1536×1024 순수 지형 원화. 텍스트·정치적 국경·클릭 아이콘 없음. 읽기 쉬운 산맥·숲·강·도로, 중앙 교역로, 항만 공간을 포함.
- world_concept.png: 동일 지형에 임시 3국과 북부 위험 지역을 구분한 설명 레이어를 합성.
- world_overlay_guide.png: 동일 지형에 서부 영주령 후보 5곳, 동부 4곳, 남부 4곳 및 왕도·항구·요새·광산·위험 지역 후보를 표시.
- map_locations.json: 같은 지도 기준 정규화 좌표, 지역·지점 ID와 중앙 연결 육로 후보. JSON 좌표로 가이드의 원형 표시를 직접 생성했으므로 위치가 일치한다.
- world_concept_overlay.png / world_ui_overlay.png: 안내를 분리한 투명 RGBA 레이어. 정치적 국경은 미정이며 향후 독립 UI 레이어로 관리한다.
- generation_prompt.txt: 사용한 생성 지시.

## 배치 검토 기준
- 북부 약 40%는 미개척 설산·빙하 / 원시림·마수 / 마나 이상·유적. 인간 국가의 영토가 아니다. 중남부 약 60%는 문명권. 비율은 구도 지침이며 정확한 영토 면적을 의미하지 않는다.
- 서부는 금빛 농경 평야와 강, 동부는 고원·절벽·마나 광산 공간, 남부는 항만·구릉·일부 농경지. 5·4·4개 영주령 후보는 왕도 후보와 별도로 집계한다.
- 중앙은 세 방향의 교역 육로가 만나는 요충지. 강 사이 통로·산맥 고개·요새·마나 광산 후보를 확보했다. 가이드의 선은 육로 후보이며 국경이 아니다.
- 북부 작은 유적과 지형 형상은 시각적 분위기 표현이며 공식 장소가 아니다. 지도의 모든 위치·도로는 수정 가능한 시안이다.
- 이전 시안은 drafts/v01/에 보존했다.

검증: 3종 지도와 2종 오버레이의 해상도 일치, 좌표 범위(0~1), 고유 ID, 영주령 수(5·4·4), 이미지 SHA-256 연결을 확인했다. 이동 실행은 아직 연결되지 않았으며 게임 UI 표시 연결은 아래 기록에 따른다.
