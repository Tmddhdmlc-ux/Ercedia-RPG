# 에르세디아 RPG 세계지도 시안 v0.1

**비정설 지리·UI 검토용 시안. 국명·국경·도시·영주령·위험 지역 위치는 확정하지 않았다.** WORLD.md의 정식 설정을 수정하지 않는다. 특정 기존 마을의 위치도 연결하지 않았다.

- world_base.png: 텍스트·UI 포인트 없는 지형 원화. 거대 중심 대륙 1개, 주변 군도, 외곽 미지의 바다·땅.
- world_concept.png: 같은 지형 위에 북부 미개척지, 중남부 임시 3국, 중앙 분쟁지를 설명한 시안. 선은 국경을 의미하지 않는다.
- world_overlay_guide.png: 같은 지형 위에 왕도·영주령·항구·요새·던전·마수·이상 지역의 후보 자리를 표시한 가이드.
- world_concept_overlay.png / world_ui_overlay.png: 위 안내 요소만 분리한 RGBA 투명 레이어. 최종 게임에서 필요에 따라 교체·숨김 가능.
- overlay_points.json: 상단 좌측 기준 정규화 좌표(0~1). 3국별 왕도 1개와 영주령 3개 후보이며, 추후 3~5개 영주령으로 확장 가능.

북서부는 설산·빙설, 북중부는 원시림·마수 후보, 북동부는 수정·마나 이상·유적 후보로 표현했다. 북부는 인간 국가의 영토로 칠하거나 도로로 연결하지 않았다. 서부는 금빛 농경 평야와 강, 동부는 푸른 고원·협곡·광맥, 남부는 따뜻한 해안과 항구 공간, 중앙은 회갈색 폐허와 접경으로 구분했다.

지도 원화의 작은 폐허나 외곽 땅 형태는 분위기 표현이며 공식 장소가 아니다. 이미지 해상도는 1536×1024, 모든 가이드와 레이어가 같은 크기·위치를 사용한다. 지형·국가·전선·클릭 포인트는 사용자 검토 이후 수정한다.
