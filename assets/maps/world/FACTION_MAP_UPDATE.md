# 에르세디아 RPG — 세력 지도 업데이트 지시 v1.0

## 목적
최신 세계지도 위에 공개 세력의 본거지·분회·성지·주요 인물의 대표 위치를 **커서 올림/키보드 포커스 툴팁**으로 표시할 수 있게 만든다.

## 데이터 출처
- `assets/maps/world/faction_locations.json`: **37개 공개 거점**의 ID, 카테고리, 영지 앵커, 정규화 좌표, 픽셀 좌표, 대표 인물, 단체, 공개용 설명.
- `assets/maps/world/map_locations.json`: 영주령 13개·왕도 3개의 현재 마커 및 지역 좌표, 변경하지 않는다.
- `FACTIONS.md`: 단체의 실제 정체·인물·복식/외형·정치적 배경.
- `FACTIONS_SECRET.md`: GM 비밀 참고용으로만 사용. 지도 툴팁에 직접 노출 금지.

## 반영 범위
- 기사단 본부 6개
- 독립 마법탑 5개
- 11교단의 성지 11곳 + 현직 성자/성녀 11명의 이름
- 모험가 길드 본관/분회 3개, 용병/해상호위 2개
- 상단 본회/지점/연락소 5개
- 공개 민간조직/중재 지점 5개
= **37개 지도 위치**.

## 지도 표시 규칙
1. 기존 `world_main.png`의 지형·국명·영지명·주요 마커는 유지한다. 새 거점은 기존 원화에 텍스트를 모두 구겨넣지 말고 **별도 HTML/SVG 클릭 레이어**로 표시하는 게 바람직하다.
2. 전체 지도에서는 과밀을 막기 위해 거점 표시를 요약하거나 숨긴다. **왕국/영주령 확대 시** 해당 권역의 세력 아이콘을 표시한다.
3. 마우스 오버/키보드 포커스로 `tooltip`을 표시하고, 클릭/터치 시 상세 패널에 `name`, `group`, `leader`, `detail`을 표시한다.
4. `anchor_id`가 영지 W1~S4 또는 왕도 CW/CE/CS에 대응한다. `x/y`는 그 앵커 주변에 이번에 배치한 **차기 지도 UI용 세부 마커 제안좌표**이며 실제 정밀 측량된 시가지 위치가 아니다. 지도에서 부적절한 물/산 등의 지형에 놓이면 Work가 소폭 조정하여 JSON에 함께 반영한다. **확정된 영주 중심 좌표는 절대 이동하지 않는다.**
5. 세린/써니 빌리지의 대륙상 위치는 미정이므로 새로운 핀을 임의로 만들지 않는다.
6. 쇠갈퀴 용병단 야영지는 이동식임을 명시하고 영구 불변 고정성채로 표시하지 않는다.
7. `FACTIONS_SECRET.md`의 비밀 토벌 연락망, 칠대마왕 점조직 및 봉인 본체 위치는 **공개 지도 목록에 절대 포함하지 않는다.** 비밀 발견 시 별도 정보 접근 레벨에 따라 GM이 해금해야 한다.
8. 기존 지도 코드 `web/map-data.js`는 영주령 데이터의 미러이므로 이번 작업에서 임의로 덮어쓰지 않았다. Work가 UI 구현 시 `faction_locations.json`을 별도 모듈로 읽어 통합한다.
9. 모바일에서는 호버가 없으므로 터치로 동일한 상세 내용을 본다. 외부 UI/Tampermonkey가 사용할 수 있도록 아이템 ID를 안정적으로 유지하고 새 갱신 시 브리지/상태 스키마 호환성을 유지한다.

## 검증 기준
- 37개 거점 ID 중복 없음, x/y 0~1 범위, 앵커가 기존 지도 위치에 실존.
- 한 영지에 여러 곳이 겹쳐도 최소 1개 표시 및 목록 탐색 가능.
- 지역 확대/전체지도/대화탭/게임 상태 복원에서 핀과 툴팁 정상.
- 캐릭터의 **현재 실시간 위치**는 거점 마커와 다르다. `leader`는 기본 활동 담당자이지 항상 그곳에 머무는 의미가 아니다.
- 현재는 **데이터 배치 단계**. 이미지/클릭 레이어 실제 변경과 브라우저 테스트는 Work가 수행한다.
