## 10. 제작 지시 요약

이 시트와 저장소 규칙을 읽고, 해당 캐릭터 고유 외형으로 카툰풍 중세 판타지 초상화와 전신 투명 RGBA 스탠딩을 제작한다. 세린과 같은 제작 절차를 사용하되 세린과 같은 얼굴로 만들지 않는다. 설정 시트 → 기준 초상화 → 기준 전신 스탠딩 → 원본 승인 후 각 표정 9종 → 승인 자산 업로드 → CDN → 실제 비주얼 노벨 UI 검증 순서를 따른다. 원본 승인 전 기존 자산을 덮어쓰거나 표정 전체를 생성하지 않는다.
