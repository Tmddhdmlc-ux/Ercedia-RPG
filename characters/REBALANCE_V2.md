# NPC 100명 성장·전투 재분배 v2.0

- 업데이트 파일: `characters/npc_roster_100.json` (100개 항목 전체).
- **신규 항목:** `level`, `xp`, `xp_to_next`, `unspent_stat_points`, `level_hp_bonus`, `realm_awarded_bonuses`, `realm_damage_multiplier`, `creature_damage_multiplier`, `combat.speed`, `combat.base_attack_min/max`. 기본 스탯과 HP/MP 재산정.
- **기준:** `COMBAT_GROWTH.md`, `PROGRESSION.md`, `MONSTER_RANKS.md`.
- **주의:** 초기 NPC들의 예전 레벨업 실제 이력은 없으므로 현재 레벨/스탯 배분과 레벨업별 STR 연동 HP는 **초기 시뮬레이션용 재구성값**. 개별 과거 사건이나 실제 돌파 깨달음을 만들어내지 않는다. 모든 캐릭터는 새 캠페인의 현재 전력 기준으로 시작한다.
- 인간·마수의 이름, 외형, 소속, 계급/경지, 원래 지정 위치는 바꾸지 않았다.
- 기사 경지 배율: 베이직 ×1.00, 익스퍼트 ×1.25, 하이퍼 ×1.65, 마스터 ×2.20. 마수는 별도 잠정 배율(하급 1, 중급 1.25, 상급 1.55, 엘리트 1.95, 미스틱 2.45). 이 마수 배율은 전투 테스트 전 초안이고 기사 경지로 취급하지 않는다.
- `combat.base_attack_min/max`는 10~20 주사위+근력/민첩만 반영된 **명중 전 물리 기초 원시피해 범위**. 무기/스킬/방어/경지/마수 보정은 출력값에 아직 적용하지 않았다.
- MP와 HP는 시작 기준 전부 회복된 상태이며, 이후 부상·마나 소비는 세계 상태에서 따로 갱신.
- 기존 세린·영주·군주·성자·기사단장 등 기존 핵심 캐릭터는 이번 파일의 신규 100명에 포함되지 않으며, 그들의 스탯 재조정도 이루어지지 않았다.
- 레벨을 올려 경지를 자동 돌파시키거나 하이퍼의 고유능력을 수치로 생성하지 않는다. 깨달음은 서술로만 판정.
- UI 최신 상태창은 앞으로 위 스탯과 무기/경지 보정 분리 값을 읽도록 연결할 수 있다. 실제 UI/전투 엔진 코드는 이번 작업에서 변경하지 않았다.
