## 이미지 제작 AI에 전달하는 방법

1. JSON의 공통 `art_guidelines`와 대상 NPC 한 명의 모든 필드를 함께 전달한다.
2. `appearance`는 키·체형·고유 얼굴 특징, `hair`는 색·길이·묶음·수염, `eyes`는 색·눈매를 지정한다.
3. `outfit`은 의복 재질·겹침·신발, `colors`는 고정 색명과 HEX 팔레트, `props`는 구별 가능한 일상 소품이다.
4. `silhouette`는 체형·의복·소품의 외곽 식별점이며, `image_notes`는 인물별 배치와 금지 사항이다. 소품이 얼굴을 가리거나 별도 배경처럼 화면을 채우지 않게 한다.
5. [초상화 규칙](../PORTRAIT_RULES.md)과 [전신 규칙](../STANDING_ART_RULES.md)을 구분하고 [캐릭터 파이프라인](../CHARACTER_PIPELINE.md)을 따른다. 생성 이미지를 검수하기 전 기준 원화나 UI 등록 이미지로 간주하지 않는다.

## 운영 범위

- 등록 상태는 `image_status=uncreated`, `stat_status=not_assigned`이다. 이미지 파일·전투 수치·경지·고유능력은 생성하지 않았다.
- 삼국과 영주령의 공개 지리·생활상만 사용한다. 민간 직무를 새로운 공식 길드나 상단 이름으로 확정하지 않는다.
- 성격·말투는 동적 대화를 위한 출발점이다. 이 파일만으로 의뢰·거래·전투·관계 변화·현재 위치를 확정하지 않는다.
- 도적 이름과 행적은 플레이어가 실제로 알아낸 경우에만 공개한다. 세계관 상위 비밀이나 마왕 연관을 임의 부여하지 않는다.
- 신규 설정 파일은 기존 GitHub 설정 탐색·동기화 범위에 포함된다. 실행 엔진의 캐릭터 ID 허용 목록·아트 등록은 별도 연동 단계이며, 이 문서가 UI에서 표시되었다는 의미는 아니다.
