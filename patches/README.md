# 에르세디아 RPG — 우선순위별 패치 실행 지시서

사용자 지정 순서를 유지한다. 설정 파일 존재와 실행 엔진 완성을 구분하고, 기존 구현을 먼저 검사해 동작하는 부분은 재작성하지 않는다. 최신 main을 병합한 기준: f4e6ee1.

1. [레벨업·능력치](01_PATCH.md) — 기존 유지; 투자 경계와 저장 회귀 검증
2. [장비](02_PATCH.md) — 기존 유지; 300종 전체 장착/해제 회귀 검사
3. [검술서·마술서](03_PATCH.md) — 기존 보완; 70개 스킬 저장 및 검술서 위력 검증
4. [전리품](04_PATCH.md) — 신규 처리 연결
5. [던전](05_PATCH.md) — 신규 처리 연결

## 적용 방식
1~3과 7~8은 기존 엔진을 보존하고 회귀 검사한다. 누락된 4~6, 9~13은 순번에 맞춰 검증 가능한 추가 처리기로 연결한다. UI는 GM 요청을 보내고 확인된 system_events를 기존 채팅 정산 경로에서 처리한다. 전투와 난수 판정의 주체는 기존 ChatGPT GM이다. 가격·드롭 성공·연간 사건의 확정 결과를 임의 하드코딩하지 않는다.
