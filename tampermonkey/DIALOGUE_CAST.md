# 다인 대화 — UI 2.1.6 / ercedia_scene v1 선택 확장

기존 npc 한 명 장면은 그대로 사용한다. 여러 인물이 실제 같은 현장에 있다면 선택 필드 cast에 1~3명을 등록한다. npc는 주 대화 상대 또는 null이며 주 대화 상대가 있다면 cast에 포함해야 한다.

```text
cast: [{id, outfit, emotion, speaker, profile?}, ... 최대 3명]
dialogue: [{speaker, speaker_id?, text, emotion?}, ...]
```

cast는 npc와 같은 등록된 인물/복장/표정 규칙을 따른다. 중복 ID, 네 번째 인물, 미등록 인물/복장/표정은 검증에서 거절한다. 각 인물 대사에 speaker_id로 cast의 ID를 지정한다. 나레이션이나 플레이어 대사에는 speaker_id를 넣지 않는다. 기존 대사는 이름이 cast.speaker와 정확히 일치하면 화자를 찾을 수 있지만 새 응답은 ID를 명시한다.

## 배치

- 배열 순서대로 좌우 또는 좌·중앙·우 배치. 각 영역은 동일 너비이고 별도의 overflow:hidden 영역이다. 인물의 이미지가 옆 인물 영역에 겹쳐 나가지 않는다.
- 스탠딩은 가로세로 비율을 유지한다. 3명 장면에서는 어깨/몸의 가장자리 일부가 각 영역에서 잘릴 수 있다. 이미지 자체를 찌그러뜨리지 않는다.
- 현재 화자는 밝게 강조하고 ‘대화 중’을 표시한다. 다른 인물은 조금 어둡게 표시한다. 나레이션에서는 모두 같은 밝기다.
- 이전 대사로 돌아가면 각 인물 표정을 해당 시점까지 다시 계산한다. 다른 화자의 emotion을 세린에게 적용하지 않는다.
- 세린의 승인된 몸·얼굴 원화와 faceFit 좌표를 같은 캔버스 안에서 함께 확대한다. 얼굴 로드 실패 시 기본 얼굴 유지, 몸 로드 실패 시 떠 있는 얼굴 숨김과 이름 표식의 오류 표시.
- 인물을 클릭하거나 이름 버튼을 누르면 해당 인물 메뉴/정보/생활·관계 행동을 사용한다.
- 3명의 DOM 및 이미지 슬롯을 재사용한다. 원화 재생성 없음. 전투 화면에서는 대화 인물 영역을 숨기고 기존 전투 UI를 사용한다.

## 엔진·호환

현재 참가자와 speaker_id는 저장/복원 및 다음 GM 요청에 포함한다. 각 참가자의 공개 프로필 변경과 첫 만남/동행/목격/소문 증거는 기존 NPC 생활 엔진에 연결한다. 이미 다른 장소에 있다고 확정된 NPC나 국경을 넘지 않은 NPC를 원격으로 등장시키는 것을 허용하지 않는다. 캐릭터 수치·세계관·이미지 원본은 변경하지 않는다. 주인공의 새 원화는 만들지 않는다.

기존 런처가 장면 JSON을 전달하므로 재설치 없이 게임 UI 업데이트로 적용된다. 과거 응답에 cast가 없으면 이전 1인 표시를 유지한다. 말하는 이름만 여러 개 적는 것으로 참가자 그림을 임의 추정하지 않는다. 네 번째 인물은 다음 장면에서 참가자를 교체한다.

## 검사

tests/scene-cast.test.mjs 추가 6개: 3인 저장 복원/기존 단일 장면, 참가자 및 화자 검증, 화자별 표정과 대사 뒤로가기, 이미지 슬롯 재사용/클릭 대상, 몸 실패 시 얼굴 숨김, GM 출력 지침.

최신 main 병합 후 전체 자동 검사 173개와 통합 빌드 통과. 실제 브라우저 화면 비율·클릭 및 설치된 Tampermonkey/GPT 응답 테스트는 이 단계에서 수행하지 않았다. 모바일 전용 수정 없음.
