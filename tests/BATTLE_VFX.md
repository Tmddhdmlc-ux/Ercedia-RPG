# 전투 이펙트 2.1.20

- 승인된 12종 원소 시안을 실제 VN 전투에 통합했다. 등록된 70종 skill_id는 원소 연출과 기술별 SVG 형태·각도·변형을 공유한다. 신규 임의 기술은 명시된 원소의 기본 연출을 사용한다.
- 전기: 2.2초, 타격 0.55초. 어둠: 2.4초, 타격 0.672초. 기존 3.6초 / 타격 1.512초에서 단축했다. 물·불·바람·빛의 빠른 전개와 긴 잔광을 유지한다.
- 정면 관찰 시점, 대상 위치에 이펙트 정렬. 타격에 피해 숫자·HP/MP·효과음을 동기화한다. 원본 스탠딩이나 세계관 수치를 수정하지 않는다.
- 기존 한 턴씩 읽기, 일시정지, 속도, 건너뛰기, 다시보기 및 보상 1회 확정 구조를 유지한다. 회피와 완전 방어에는 성공 타격 폭발이 나오지 않는다.
- 공유 코드: web/battle-vfx.js, web/elemental-vfx.js, web/skill-effects.js. 미리보기와 본 게임이 같은 연출 코드를 사용한다. 외부 이미지 에셋 없이 Canvas/SVG로 생성한다.

## 검술 리마스터 2.1.24

검술 30종을 화살표·조준선 위주 SVG에서 대상 위치의 점점 가늘어지는 검격 리본, 백색 검날 핵심광, 금속 불꽃으로 교체했다. 등록된 기술 이름과 설명에 맞춰 횡베기·찌르기·시간차 연속 검로·역베기·내려베기·가드·자세를 구분한다. 일섬은 1초의 빠른 단일 검광, 유성 찌르기는 준비가 긴 2초 연출이다. 서리 검무의 은빛 잔상은 냉기 피해를 추가하지 않는다. 검격 잔상 개수는 판정 횟수·피해량을 바꾸지 않는다. 회피는 타격 섬광을 표시하지 않고 방어는 가드 연출을 사용한다.

원본 캐릭터 이미지 및 기술 데이터는 변경하지 않았다. Canvas 미지원 시 화살촉 없는 SVG 검광을 사용한다. 물·불·바람·전기·빛·어둠 연출은 유지한다.
