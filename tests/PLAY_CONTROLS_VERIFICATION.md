# UI 1.8.2 플레이 편의 수정

- 전투 기본값은 manual=true. 한 행동의 연출이 끝나면 읽기 대기하고 다음 턴 버튼/화면 클릭으로만 다음 행동 진행. 자동 재생은 사용자가 선택할 때만 사용. 일시정지한 읽기 대기에서 다음 턴을 누르면 새 행동이 정상 재개되도록 수정.
- 주인공 스탠딩은 계속 숨기고 상대를 중앙에 표시. 상단 양측 HP/MP 정보는 유지.
- 전투 MP 바의 고정 grid-row=5가 MP 글자와 충돌할 수 있어 자동 행으로 수정. HP/MP 바를 크게 표시.
- 화면 전체 갱신 때 chat.controls()도 갱신해 선택지의 disabled 상태가 이전 화면에 남지 않도록 보강. 클릭과 숫자키1~4 모두 기존 action/요청ID 경로로 전달. 입력창에서 숫자를 타이핑하거나 한글 조합 중이면 단축키를 실행하지 않음.
- 모든 일반 탭의 상단 HUD에 이름/Lv/HP/MP/EXP 숫자와 세 종류의 바 유지. 글자와 바 높이를 확대.
- 기존 테스트113개 및 추가 회귀2개 총115개 통과. 자동 전투 전환, 저장 호환, 선택지 재시도, 숫자4개, Enter/한글 조합 등 검사.
- 이번 수정에서 사용자의 실제 ChatGPT/Tampermonkey 전송은 재검증하지 않음. GPT 원본 입력창 감지·전송 문제는 UI 활성 상태 수정만으로 성공을 보장하지 않는다.
