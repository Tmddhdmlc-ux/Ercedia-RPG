## 실제 로컬 브라우저 조작

`/tests/ordered-patches-demo.html`의 분리된 테스트 세이브에서 확인:

1. 등록 마수 전투 진입, 수동 다음 행동, 일시정지·재개, 0.5배속, HP/MP 바, 주인공 스탠딩 숨김.
2. 즉시 종료 후 재료 1개 지급. 다시보기 후 지급 수량 유지.
3. 던전 입구 → 두 번째 구역 → 보스 구역. 최종 XP 93, 재료 2개, 최초 클리어 표시.
4. 보스 다시보기와 저장 복원 후 XP 93 / 재료 2개 / 확정 전투 3회 유지.
5. 상점 견적 → 구매 → 판매 → 경매 70 예치 → 낙찰 후 장비 1개 지급. 최종 재화 870.
6. `/tests/quest-demo.html`: NPC의 개인 의뢰 카드에서 수락, 의뢰탭 등록 및 0/1 진행 표시.
7. `/tests/launcher-demo.html`: 실제 런처 코드와 가짜 GPT 편집기를 사용해 Enter 전송 1회, 요청 ID 대응, ‘자동 입력·전송·응답 반영이 완료된 검증 장면 1’의 게임 대사 갱신 확인.

## 검증 범위와 실제 GM 연결

브라우저 검증의 가격·전투·응답은 명시된 **고정 GM 테스트 데이터**다. 실제 ChatGPT 서버를 호출하거나 사용자 채팅에서 전투를 진행한 검사는 아니다. 기존 자동 전송·응답 파싱 경로에 `system_events`를 연결했으며, 실제 GM은 `tampermonkey/WORLD_ENGINE_SCHEMA.md`에 맞는 검증 가능한 사건을 생성해야 한다.

가격, 드롭 성공, 동행 승인, 국경 판정, 연간 사건 결과를 UI가 임의 결정하지 않는다. 달력은 사건 후보와 월간 갱신을 생성하며 조건부 사건의 확정 결과는 GM 판정으로 적용한다. 입력이 잘못되면 턴 전체를 거절하고 기존 상태를 유지한다.
