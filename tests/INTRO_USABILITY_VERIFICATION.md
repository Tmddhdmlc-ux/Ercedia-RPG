# 프롤로그 안내 개선 — UI 2.1.2

이름 입력 → 모습(선택 사항) → 배경 선택 → 위험 앞 행동 선택 → 패시브 확인 → 기존 지도에서 시작 지역 선택 순서를 유지한다.

- 이름은 게임 속 이름이며 실제 자기소개는 필요하지 않음을 명시.
- 모습은 남성/여성/나중에 정하기 버튼, 또는 선택적인 직접 입력. 기존 자유 서술 저장은 보존. 모습으로 능력치나 주인공 원화를 부여하지 않음.
- 배경/행동은 자기 경험을 적는 질문이 아니라 만들고 싶은 주인공의 선택임을 안내.
- 선택 카드에 승인된 패시브 후보 및 효과 표시. 클릭 즉시 다음 화면으로 이동하지 않고 선택 강조 후 ‘다음’으로 확정.
- 답변을 고르지 않고 Enter/다음으로 질문을 넘기는 경로 차단.
- 두 답변이 다르면 기존 규칙대로 두 패시브 중 하나를 선택. 기본 능력치·패시브·지역 원본 데이터는 변경하지 않음.
- 기존 생성 초안, 뒤로가기, 자유 외형 입력, 저장 형식 호환 유지. 모바일 전용 수정 없음.
