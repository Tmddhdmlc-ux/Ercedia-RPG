# 세린 등록 수치 연결 검증 — UI 1.4.2

원본: main `2eadbb3`, `characters/serin.json` 및 생성된 `web/catalog-data.js`.
Lv.18 / 베이직 나이트 / HP330 / MP136 / STR25 DEX26 INT14 CON22 MANA16 / 속도31 / 기초 피해31~41.

## 변경

- NPC 조회 시 세이브와 장면의 null 숫자만 원본 값으로 보완한다. 원본이나 저장 객체 자체를 덮어쓰지 않아 런처의 저장 버전 1 복원 비교를 유지한다.
- 과거 전체 미정 프로필의 `levelHpBonus:0` 자리표시자는 원본 65를 막지 않는다. 수치가 실제로 배정된 프로필의 0은 유지한다.
- 이후 NPC 변경 응답의 null은 기록된 부상·소모·관계 수치를 지우지 않는다. 숫자 0(전투불능 포함)은 실제 기록으로 유지한다.
- 정보창, 상태창 인물 목록, 게임 브리지, GPT 요청 및 전투 시작 검증이 공통 조회 함수를 사용한다.
- 이전 이름만 지정한 주인공 세이브는 상태창 열기/행동 전송 때만 player_default 초기값을 적용한다. 알려진 전투 수치·성장·기사 경지·스킬이 있는 세이브는 초기화하지 않는다. 이름·직업·인벤토리·대화 기록은 유지한다.
- 예전 연출 데모의 Lv.1 세린은 테스트 세이브의 명시적 합성 수치로 분리한다. 공식 세린의 초기값을 바꾸지 않는다.

- 사전 작성한 테스트용 공격 재생 및 원래 장면 복귀: HP312/330, MP136/136. 정산 1회.
