# 자동전투 UI 1.3.0 검증 — 2026-10-09

## 실행

기존 로컬 서버에서 `/tests/battle-demo.html`을 열고 시나리오를 고른 뒤 **데모 전투 시작**을 누른다. 이 페이지는 실제 채팅 세이브와 분리된 저장·응답 브리지를 사용한다. 데모 기술, 수치, 아이템, 부상은 승인 세계관 설정에 추가되지 않는다. 일반 게임은 `/?game=1`, ChatGPT에서는 기존 Tampermonkey 런처의 UI 업데이트로 실행한다.

## 실제 브라우저에서 확인한 내용

- 대화 중 적대, 이동 중 도적 습격, 던전 마수 조우, 정식 결투, 기습의 고정 응답으로 기존 VN 화면이 전투 화면으로 전환된다. 별도 전투 탭은 없다.
- 돌진, MISS 회피, 방벽 방어, 반격, 피격 숫자, 치명타 흔들림, 화염 시전, 퇴장 연출을 재생한다. 하이퍼 고유능력의 별도 고정 데이터로 컷인과 MP 100→90을 확인했다.
- 마법 사건 중계를 표시하는 시점에 플레이어 HP 100→72, 상대 MP 100→93을 확인했다. 자원 표시는 타격 시점에 변하고 저장된 최종 플레이어 값은 완료 전까지 변하지 않는다.
- 일시정지/재개, 0.5/1/2배속, 즉시 종료, 다시보기를 클릭했다. 전투 중 탭과 행동 입력이 잠긴다.
- 자연 종료와 즉시 종료의 결과는 HP 54, MP 100, XP 45, 검증용 동전 2개로 동일했다. 다시보기 후 즉시 종료해도 정산 기록은 1회, XP와 아이템 수량은 그대로였다. 종료하면 입력·탭·대화 화면이 복구된다.
- 일시정지한 재생 저장을 기존 복원 메시지로 되돌렸다. 저장값의 정규화 비교가 통과했고 사건 위치·속도·일시정지 상태가 유지됐다.
- 회피 피해를 5로 변조한 JSON은 재생되지 않았다. 기존 HP/MP 100, XP 0을 유지하며 검증 이유와 수정 요청/기존 장면 유지 버튼을 표시했다.
- 데스크톱 1280×800, 모바일 390×844에서 화면 배치 및 클릭 조작을 확인했다. 모바일에서 속도 선택·일시정지·다시보기·즉시 종료를 조작했다. 실제 휴대전화의 물리 터치는 아직 검증하지 않았다.
- 브라우저 오류·경고 로그는 없었다. 승인된 세린 신체와 표정은 같은 비율의 부모 안에서 함께 움직이며 좌우 반전하지 않는다.

## 자동 검사

`node --test tests/*.test.mjs`: **41개 통과, 실패 0**. 기존 30개 검사와 전투 11개를 포함한다.

전투 검사는 피해 공식, 경지 배율, MP 비용, 현재 주인공 스탯·장비 보정, 사망 후 행동, 회피 피해, 반격 순서, 기술 보유, 승인 이미지, 최종 자원·보상·부상, XP 이월·레벨 HP·미배분 포인트, 깨달음 수치화 금지, 다수 참가자 구조를 확인한다. 기존 v1 저장의 키가 늘어나지 않는 것과 선택적인 재생 저장의 왕복 호환성을 확인한다.

## 구현 범위와 미검증 범위

실제 ChatGPT 런처가 전달하는 기존 `ercedia_scene` 안의 선택적 `battle`을 재생하도록 연결했고, 요청에 관련 세계관 문서와 전투 스키마 참조를 추가했다. 이번 브라우저 검증은 **사전 작성된 응답 데모**다. 로그인된 ChatGPT가 새 스키마를 실제로 생성하고 런처가 자동 추출하는 전체 흐름은 이번 작업에서 검증하지 않았다. AI 대화 API는 추가하지 않았다.

UI는 제공된 공식과 자원·보상 일관성을 재검산한다. GPT가 기술·NPC 공개 스탯·상성 판단의 근거로 적은 설명이 세계관에서 실제 승인된 내용인지까지 자동 판정할 수는 없다. 그 부분은 ChatGPT가 승인 문서를 읽고 판정해야 한다.

주인공·도적·마수의 승인된 런타임 스탠딩은 없어 이름이 있는 임시 영역으로 표시한다. 세린 원화를 다른 인물에 사용하지 않았고 검토 대기 NPC 원화도 등록하지 않았다. 기존 이미지·세계관 공식은 변경하지 않았다.

작업 중 main에 추가된 장비 300종 및 지역 던전·시설 문서도 확인해 보존했고 GPT 요청에 규칙 참조를 추가했다. 장비 장착 UI·카탈로그 효과 자동 계산·던전 입구 지도 핀은 이번 전투 관전 기능의 구현 범위가 아니다. 전투 검증은 현재 저장에 확정된 능력치와 장비/상태 보정값을 사용한다.
