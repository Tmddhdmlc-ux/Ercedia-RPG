# 새 게임 편의 규칙 로드 검증

- 배포 UI: 2.1.11. 기존 엔진·화면·저장/장면 스키마 v1 유지.
- BOOTSTRAP 직후 GAMEPLAY_CONVENIENCE_RULES.md v1.1 이상을 필독하도록 시작 안내와 설정 첨부 지시를 보완했다.
- 예시 밖의 상황도 선제적으로 판단하며 일반 이동·치료·귀환·휴식·반복 절차를 자동 후처리하고 중요한 선택만 질문하도록 GM에 지시한다. 실제 상태 변화는 기존 사건 처리에 한 번만 반영한다.
- 필수 파일 누락, v1.0, 포괄적 후처리 절이 빠진 불완전 원문은 로드/첨부 생성을 거부한다. 새 게임 로드 실패 시 기존 저장을 보존하며 GM 요청을 보내지 않는다.
- 전체 자동 검증: 207개 통과. 새 게임 컨트롤러 → GitHub 설정 로드 → 실제 채팅 요청 생성 → 전체 파일 첨부 → 고정 커밋/파일 수 읽기 확인 검증을 포함한다.
- 실시간 확인: `node tests/verify-convenience-live.mjs tests/CONVENIENCE_LIVE_RESULT.json`. 실제 GitHub main에서 설정 228개를 읽고 캐릭터 이름 입력 전 새 게임 요청을 생성했다. 원문 전체, 파일 순서, 시작 지시를 확인했다. 결과는 CONVENIENCE_LIVE_RESULT.json에 저장했다.
- 검증 범위: 새 게임은 실제 운영 컨트롤러를 호출하는 자동 UI 하네스에서 시작했다. GM 읽기 확인 응답은 검증용 모의 응답이다. 로그인한 ChatGPT/Tampermonkey에서 실제 모델의 열람·후처리 플레이 또는 20턴 진행은 검증하지 않았다.
