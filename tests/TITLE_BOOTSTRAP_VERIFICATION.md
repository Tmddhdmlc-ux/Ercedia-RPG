# UI 1.5.0 — 메인 타이틀 / 새 게임 설정 자동 전달

- 첫 화면: 사용자가 지정한 `아르세디아RPG`, 새게임 시작, 불러오기. CSS 글자 등장·발광·빛 회전·별 이동, 모바일 크기와 동작 줄이기 설정 지원. 원본 이미지/세계관 이름 변경 없음.
- 불러오기는 해당 채팅/브라우저의 저장 상태를 이어간다. 새 게임은 기존 프롤로그로 진입하며 완료 전에는 기존 플레이 데이터를 지우지 않는다. 취소하면 타이틀로 돌아간다. 타이틀에서 저장된 전투의 사건 시간은 진행하지 않는다.
- 새게임 시작 시 GitHub main 커밋과 전체 파일 목록을 실제 요청한다. 같은 커밋의 게임 규칙 Markdown, 캐릭터 시트/JSON, 장비/기술서/지역/던전/전리품 JSON, 이벤트/지도 자료를 모두 읽는다. 개발자 AGENTS/README 및 제작 계획/이미지 바이너리는 캠페인 규칙에서 제외한다.
- 새 캠페인의 공개 NPC 수치는 이 스냅샷에서 생성한다. 기존 세이브와 이전 게임 백업에 새 초기값을 덮어쓰지 않는다. GM 전용 원문은 세이브·캐릭터 정보창에 넣지 않는다.
- 실제 네트워크 확인: main `2501a9537166e8e831fe20ac877f36b0a24f3476`의 **103개 파일**, 합친 설정 약 **706,623자**. 읽은 사실은 클라이언트에 관한 확인이며 GPT의 이해 완료를 뜻하지 않는다.
- 후속 최신 main `a9f1caf9f5d9af2471e03ca3b74c488aba195a36` 재확인: 퀘스트 템플릿을 포함한 **107개 파일**, 첨부 원문 **723,524자**, 첫 요청에 추가하는 안내 **456자**. 이후 파일 수는 최신 main의 실제 목록에 따라 달라진다.
- 전체 원문은 텍스트 첨부 파일로 전달한다. 요청문에는 원문이 아니라 파일명·커밋·읽기 지시·장면 형식만 넣는다. 첫 GM 응답에 동일 커밋 및 파일 수의 `settings_loaded` 선언을 요구한다. 선언은 GM의 확인 응답이며 문서 전부를 이해했다는 독립 검증은 아니다.
- Tampermonkey **런처 1.1.7**: 공개 file input에 설정 파일을 넣고 화면상의 첨부 파일명 확인 후 짧은 요청을 기존 연결로 전송한다. 첨부 입력을 찾지 못하거나 실패하면 전송을 진행하지 않는다. 연결 도움의 설정 파일 다운로드/요청 복사로 복구할 수 있다.
- 런처 1.1.6 이하에서는 첫 캠페인의 자동 첨부 요청을 막고 1.1.7 업데이트를 안내한다. 브리지/장면/저장 버전은 모두 1 유지. 일반 행동에는 첨부를 반복하지 않는다.
- 원본 GitHub 접근 실패 시 새 게임 생성 전 기존 상태를 유지하고 재시도를 제공한다. 파일 첨부 실패 시 현재 시작 상태를 유지한다.
- 코드 검사 **69개 통과**: 메뉴/불러오기/취소, 저장 기록 보존, 고정 커밋 로딩, 실패 거절, 첨부 성공·실패 모의 검증, 다른 첨부 파일의 무단 전송 방지, 번들/런처 JavaScript 문법 및 기존 게임 회귀 검사.
- 실제 ChatGPT 페이지 파일 업로드·새 채팅 GM 응답 및 모바일 브라우저 클릭은 이번 단계에서 검증하지 않았다. 사용자 요청에 따라 별도 시연 없이 구현·빌드·배포한다.

로컬 타이틀: `http://localhost:4173/?game=1`.
