# 새 게임 설정 로딩 개선

새 게임·캐릭터 생성 시작에서 전체 설정을 개별 다운로드하던 경로를 최적화했다. 2026-10-09 작업 기준 362개 원문을 읽으므로 기존 경로는 main 확인·트리 조회·개별 원문 총 364요청이다. 정상 묶음 경로는 main 확인·트리 조회·묶음 다운로드의 3요청이며, 같은 실행에서 같은 main을 다시 읽으면 최신 main 확인 1요청이다. 실제 체감 시간은 네트워크 상태에 따라 달라지며 ChatGPT/Tampermonkey에서 초 단위 전후 측정은 하지 않았다.

- integration/campaign-settings.json은 기존 isCampaignSetting과 같은 전체 범위를 포함하며 GM 전용 설정도 생략하지 않는다. 화면에 원문을 표시하지 않는다.
- 묶음의 전체 경로 및 Git blob SHA가 최신 고정 커밋의 트리와 일치해야 사용한다. 누락·구버전·오류 시 개별 원문 전체 읽기로 돌아간다.
- main 확인은 no-store, 고정 커밋의 트리·묶음·개별 원문은 force-cache로 읽는다. 같은 버전의 메모리 캐시는 호출자에게 복사본을 주며 진행 상태를 섞지 않는다. 새 main은 이전 캐시를 사용할 수 없다.
- 기존 파일/전체 크기 제한, 필수 문서·운영 규칙 검증과 저장/브리지/장면 v1을 유지한다.
- 빌드는 추적된 원문에서 묶음을 재생성한다. 설정 변경 시 GitHub Actions도 묶음을 재생성하고 커밋한다. 빌드가 누락돼 묶음이 오래되면 SHA 비교 후 개별 경로를 사용한다.

campaign-settings.test.mjs는 3요청/1요청, 복사본 분리, 최신 main 전환, 누락/구버전 묶음의 전체 원문 대체 읽기를 검증한다. 기존 설정 동기화·생성 및 첨부 테스트도 유지한다.
