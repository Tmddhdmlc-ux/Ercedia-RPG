# UI REMASTER v2.0 검증

2026-10-09. 기존 VN·Tampermonkey 런처·세이브 및 승인된 원화를 보존하고 공통 색상/글자 크기/패널 배치를 개선했다.

## 변경 화면

이야기, 상태, 가방, 의뢰, 지도는 기존 기능과 ID를 유지한다. HP/MP/EXP와 레벨을 공통 HUD에 표시한다. NPC 정보는 클릭 메뉴와 상세 패널로, 아이템 설명은 클릭 선택 후 유지되는 상세 영역으로 바꿨다. 장비는 장착 전후 수치를 비교한다. 지도는 원본 이미지 좌표를 유지하며 세부 지점·인물·세력을 구분한다. 전투는 수동 한 행동 진행과 HP/MP 바, 주인공 숨김을 유지한다.

모바일은 44px 이상 주요 버튼, 하단 탭과 조정 가능한 글자 크기를 사용한다. 얼굴·신체에 동일 배율을 적용하고 이미지를 비균일하게 늘리지 않는다. 감소된 동작 설정을 지원한다.

## 정확한 화면 크기 검사

`/tests/ui-remaster-demo.html?size=...`의 고정 크기 게임 iframe에서 측정했다. 실제 휴대전화 하드웨어를 사용한 검사는 아니다.

| 게임 화면 | VN 장면 높이 | 장면 비율 | 가로 넘침 |
| --- | ---: | ---: | --- |
| 1280×800 | 428px | 53.5% | 없음 |
| 1920×1080 | 708px | 65.6% | 없음 |

360×640에서는 채팅 입력과 하단 탭을 유지하기 위해 장면이 절반보다 작다. 긴 대사는 대화 영역 안에서 스크롤한다. 가상 키보드의 실제 기기 동작은 미검증이며 visualViewport 높이 변화 대응을 구현했다.

## 화면 증거

`artifacts/remaster-before-*.png` 및 `artifacts/remaster-after-*.png`에 이야기·NPC·상태·가방·의뢰·지도·전투·모바일 전후와 추가 360/1920 크기 화면을 저장했다. 서로 다른 기능 검증용 GM 데이터가 사용된 화면도 있어 전후의 게임 진행 내용까지 동일하지는 않다.

실제 런처 코드의 Enter 입력 전달과 응답의 게임 대사 갱신, 의뢰 수락/등록, 수동 전투와 중복 보상 방지는 로컬 브라우저에서 확인했다. 전체 자동 검사 140개 및 통합 빌드 성공. 실제 ChatGPT/Tampermonkey 확장 환경에서의 검증 결과와 혼동하지 않는다.

UI 참조로 Ren'Py GUI/Screens 문서 및 Game UI Database 홈페이지를 확인했으며 다른 게임 아트를 복사하지 않았다.

## UI 2.1.74 만남 사전 안내·행동 판정 (2026-10-09)

위치가 확인되지 않은 현지 인물은 목록에 대화 불가 이유를 미리 표시하고 버튼 및 요청 생성 경로를 모두 차단한다. 현재 이동 중인 인물도 차단하며 마을·모험의 주변 인물 메뉴에 동일한 판정을 사용한다. 이전 목록을 누르기 전에 실제 위치·상태가 바뀐 경우 요청을 보내지 않는다. 위치와 만남 기록을 자동 창작하지 않는다.

통상 실행 행동의 시간·결과·수련 성과는 GM이 승인 규칙으로 판정하도록 매 턴 지침을 수정했다. 정보 문의·큰 위험·미승인 지출·중요 선택은 실행과 구분한다. 초반 성장 행동을 우선 제시하고 안전한 기초 단련 1회 실행 버튼을 추가했다. 실제 수련 성과 XP는 기존 engine_events 및 PROGRESSION.md를 사용하며 자동 경지 승급·포인트 배분을 하지 않는다. choices.kind의 허용값도 명시했다. 변경은 요청 지침이며 실제 ChatGPT가 항상 원하는 판정을 하는지 플레이 검증한 것은 아니다.

새 자동 검사는 위치 미확인 클릭의 요청 0건·상태 불변, 이동 중 만남 차단, 위치 확인 뒤 대화 활성화, 마을 메뉴의 동일 차단, 단련 요청 시 UI의 선지급 금지와 판정 지침을 확인한다. 실제 브라우저 배치·ChatGPT/Tampermonkey 플레이는 이번 작업에서 검증하지 않았다.

최종 자동 검사 445개 통과. 통합 번들 1,863,585자로 기존 런처 제한 이내이며 해시·스크립트 구문 검증과 로컬 게임 URL HTTP 200 확인을 통과했다.

## UI 2.1.75 GM 재량과 판정 기억 (2026-10-09)

GM_DISCRETION_RULES.md와 BOOTSTRAP 참조를 추가했다. 확정 세계관·성장 하한·실제 수치·ID는 유지하되 미정인 전직 방법·수련·현지 접촉 경로는 GM이 구성하도록 일반/전체 턴 요청에 적용한다. 미정 시각과 접촉 경로에 대한 과도한 금지 문구를 수정했다. 원화·직업 수치 효과·스킬을 신규 구현했다고 주장하는 지침은 아니다. 기존 고급 직업의 수치 전직 엔진을 새로 구현한 패치는 아니다.

선택 확장 gm_rulings는 공개 진행 방법을 기록한다. 장면 적용 전 전체 검증, 동일 ID 중복 방지/내용 변경 거절, 세이브·복원·다음 턴 전달을 구현했다. 전투 장면은 종료 정산 때만 해당 기록을 반영한다. 설정 등록 응답에서는 판정 기록을 생성할 수 없다. 기존 세이브에 새 필드를 강제로 추가하지 않으며 신규 캠페인에는 이전 판정을 복사하지 않는다.

자동 검사에서 공개 전직 경로가 저장·복원되고 다음 턴에 전달되는지, 기록만으로 자원·성장을 지급하지 않는지, 중복·충돌·한도 오류가 상태 변경 전에 차단되는지 확인했다. 실제 ChatGPT의 GM 재량 판정 및 브라우저/Tampermonkey 플레이는 이번 작업에서 검증하지 않았다.

최종 자동 검사 448개 통과. 통합 번들 1,865,147자로 기존 런처 한도 이내이며 해시·스크립트 구문 검증, 로컬 게임 URL HTTP 200을 확인했다. 전체 설정 묶음에 새 GM 지시서를 포함해 363개 원문을 등록했다.

## UI 2.1.78 변경분 전송·창작 기술·연습 성장 (2026-10-09)

일반 요청은 최초/불러오기 직후와 성공한 진행 10회마다 체크포인트를 보내며 사이에는 필드별 변경분과 현재 장소·시각을 전달한다. 전투·거래·학습에는 해당 최신 자원과 기술 정보를 항상 추가한다. 오류·재시도·설정 등록·타이틀 복귀는 진행 횟수를 증가시키지 않는다. 전투는 종료 정산 후 반영한다. 새 캠페인·불러오기·전송 실패 시 기준을 초기화한다. 중첩 필드 삭제는 경로로 알려 오래된 장비 효과를 유지하지 않도록 한다. 전체 설정 첨부를 자동 재전송하지 않는다. 일반 대화 예제의 요청은 기존보다 변경분 요청이 크게 감소했으며 실제 응답 시간 개선을 측정한 수치는 아니다.

learn_custom_skill 사건으로 실제 학습한 캠페인 기술을 GM-SKILL ID로 생성·저장하고 source/학습 근거를 유지한다. 기존 기술/궁극기 위조와 효과 덮어쓰기를 거절하며 학습만으로 자동 장착하지 않는다. 기존 70개 습득 목록·장착 4칸을 유지한다. 생활 패시브는 상태창에 창작 기술로 표시하고 설명의 조건과 한계로 GM이 적용한다. 등록 제작법과 실물 보상 검증을 우회하는 기능이 아니다.

실제 완료한 육체·정신·단조·탐색 연습에는 practice 사건으로 GM 판정 경험치를 지급한다. 실제 경과 시간이 필수이며 회당 해당 레벨 필요 XP의 20% 상한, 날짜/분야별 반복 감소를 적용한다. 같은 사건과 전투·의뢰/xp 보상 중복은 금지한다. 기존 레벨업·성장 포인트로 연결하고 현재 상태·최근 완료 이력에 저장한다. 대사만으로 성과를 보장하지 않으며 실제 GM이 해당 사건을 생성해야 한다.

자동 검사는 21회 진행에서 요약/변경분 전환, 실패/복원/새 캠페인 기준, 최신 전투·거래·학습 문맥, 삭제 효과·빈 소지품 처리, 단조 XP와 새 기술 학습/복원/장착, 중복 보상·기술 위조·실제 시간 검증·반복 감소·레벨업 연결을 확인한다. 실제 ChatGPT/Tampermonkey 플레이는 이번 패치에서 검증하지 않았다.

다른 작업의 2.1.76 제작 속도 패치(07e8cd6)를 반영하여 2.1.78로 배포한다. 기본 제작의 한 응답 완성 지침·미진행 응답 교정은 유지하며 성장 보상은 practice와 새 기술 학습으로 연결한다.

배포 검증에서 배포 스크립트 구문·매니페스트 해시·로컬 URL HTTP 200을 확인했다. 빌드의 문자열 치환으로 축약 변수 `$&`가 HTML로 변질되는 문제를 콜백 치환으로 수정하고 실제 배포 파일 구문 회귀 검사를 추가했다.

추가 병행 패치 d6f878c의 의뢰 필수 위협·대응·후일담 지침도 반영했다. 체크포인트·의뢰 요청·진행 중 의뢰에 해당 지침을 유지한다.

최종 자동 검사 468개 통과. 통합 번들 1877585자(런처 한도 이내), 배포 스크립트 구문·매니페스트 해시·로컬 HTTP 200을 확인했다.
